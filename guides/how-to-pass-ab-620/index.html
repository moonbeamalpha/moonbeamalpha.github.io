How to pass AB-620: Copilot Studio AI Agent Builder

A practical six-week route through planning, building, and testing agents in Microsoft Copilot Studio — from topics and generative answers to multi-agent orchestration and lifecycle management.

Updated 4 September 2026 · ~9 min read

The exam

What is AB-620, and is it for you?

AB-620 earns the Microsoft Certified: AI Agent Builder Associate credential. It targets professional developers and advanced builders who design, build, extend, and integrate custom agents in Microsoft Copilot Studio for enterprise-grade scenarios — the kind of work a job advert now describes as "Copilot Studio developer" or "agent builder" rather than a generic Power Platform generalist role.

Candidates are typically IT application developers, consultants, or ISV partners building scalable agent solutions for organisations, comfortable with Copilot Studio topics and flows, Dataverse and Power Fx, Power Platform environments, generative AI concepts, and the Model Context Protocol and Agent2Agent protocol. AB-620 became generally available on 23 April 2026, so it is a young credential without much prep material in circulation yet. The current fundamentals lead-in for candidates newer to AI concepts is AI-901, and AB-620 sits at the associate tier, terminal there — no further exam is required.

AB-620 is scenario-driven: you will be shown a Copilot Studio topic configuration or a generative-answers setup and asked what to change, or given a business constraint that rules out an otherwise sensible option. The skills measured were last updated on 21 April 2026, so anchor your study to that live outline.

Format & domains

Exam format and skills domains

AB-620 mixes question styles: single-answer and multi-select items, ordering tasks around an agent flow or a lifecycle process, and short case studies that group several questions around one Copilot Studio scenario.

  • QuestionsRoughly 40–60
  • Duration100 minutes (120-minute seat)
  • Pass score700 / 1000 (scaled)
  • DeliveryOnline or a test centre
  • ValidityRenew free every year
  • FeeVaries by country

The exam fee changes from country to country, so check Microsoft's certification page for the price where you live. Unlike most associate exams, AB-620 has just three skills domains, from the official April 2026 outline, shown below.

Six-week study plan

A realistic six-week study plan

Use the six-week plan below as a starting point if you already build in Copilot Studio or the wider Power Platform; extend it when Dataverse, Power Fx, and Foundry integration are all new at once. It tracks the outline's own skill groups, giving the biggest single group — Configure Topics — a full week to itself.

  1. Plan an agent solution, and agent flows

    Planning: integration with enterprise systems, identity strategy, channel and deployment planning, responsible AI strategy, and security and governance considerations. Then agent flows in Copilot Studio: creating a flow, building a human-in-the-loop flow, configuring actions and connectors, monitoring flows, adding input and output parameters, and error handling.

  2. Configure topics

    The largest single skill group in the outline gets its own week. Add agent flows to a topic, configure response formatting, add tools to a topic, and build advanced responses with custom prompts, custom knowledge sources, and API or Send HTTP Request actions. Then the generative answers node, adaptive cards, and managing variables.

  3. Enterprise knowledge and tools

    Connect to Copilot connectors, Power Platform connectors, and Azure AI Search as knowledge sources. Then add tools to an agent: configuring and monitoring computer use, MCP tools, an existing custom connector, and REST APIs.

  4. Multi-agent collaboration and Azure integration

    Design multi-agent solutions in Copilot Studio, integrate a Foundry agent, integrate an existing agent, and integrate a Fabric data agent, then build a multi-agent solution using the Agent2Agent protocol. Close with Azure integration: generative answers through Azure AI Search with Foundry, custom prompts against the Foundry model catalogue, and monitoring agents with Application Insights.

  5. Test and manage agents

    Evaluate agent performance: creating a test set, choosing an evaluation method, and reviewing test results. Then application lifecycle management: creating a solution, adding existing agents to it, creating and using environment variables, and implementing Microsoft Power Platform Pipelines to promote agents between environments.

  6. Review and exam simulation

    Revisit the distinctions the exam leans on hardest: connectors versus MCP tools versus agent flows, topics versus flows, and A2A versus embedded sub-agents. Then switch to sharpening: drill your weakest domain daily and sit two full-length timed practice runs. Book the exam once your readiness sits comfortably above the pass mark, not just at it.

Focus areas

The hardest AB-620 topics

With only three domains, AB-620 compensates for breadth by testing depth: fine distinctions between tools that look interchangeable at first glance. Give these five areas focused practice.

Connector vs MCP tool vs agent flow

All three let an agent do something outside the conversation, and the exam expects you to know which fits a given requirement. Connectors suit well-defined enterprise APIs with a known schema. MCP tools suit dynamic schema discovery, where the shape of the data is not fixed in advance. Agent flows suit multi-step orchestration that needs approvals or branching logic. Practise naming the right one from a one-line scenario.

Topics vs agent flows

Topics handle conversational logic — matching what the user said to the right response. Agent flows handle backend orchestration and long-running actions once a topic decides something needs to happen. Questions often describe a piece of behaviour and ask which one you would build it in, so learn to separate "deciding what to say" from "doing the work" instinctively.

A2A protocol vs embedded sub-agents

Multi-agent collaboration splits into two patterns that look similar on a diagram but behave very differently. Agent2Agent (A2A) is cross-agent protocol communication between independently deployed agents. An embedded sub-agent runs inside the orchestrator as part of the same solution. Governance, latency, and ownership boundaries differ between the two, and the exam tests which pattern a scenario actually describes.

Identity strategy gotchas

User-delegated tokens, service principals, and managed identities are not interchangeable, and the right choice depends on audience and data-access posture rather than habit. An agent acting on behalf of a signed-in user needs different treatment from one acting autonomously against a fixed data source. Read the audience and data-sensitivity clues in the scenario before picking an identity model.

ALM environment strategy

Application lifecycle management questions reward the canonical dev-to-test-to-prod path: solutions, environment variables, and connection references moved between environments through a pipeline. Any answer built around manual copy-paste between environments is a red flag, even when it would technically work, because the exam is testing whether you know the supported promotion pattern.

How to practise

Practise the way the exam works

Clicking through Copilot Studio tutorials builds familiarity with the interface, but AB-620 tests judgement calls under a business constraint, which is a different skill. Retrieval practice closes that gap: read a scenario, decide on your answer, and only then check whether you spotted the constraint that ruled out the wrong options. Doing this from memory, rather than recognising the right answer among choices, is what builds the instinct the real exam rewards.

Pair that with spaced repetition across all three domains, since Configure Topics, Multi-Agent Collaboration, and Application Lifecycle Management can each fade independently if you study them once and move on. Then close with full-length simulation: a timed, mixed-domain run is the only way to check whether you can keep spotting business constraints in the back half of the paper, once fatigue sets in. Sit at least two before you book, and review every wrong answer rather than just the score.

Exam day

Tactics for exam day

If you are sitting online, run the system check the day before and clear your desk, since proctors will ask you to show the room and remove anything within reach. Arrive early either way, because the scenario questions reward a settled, unhurried read.

With 100 minutes for 40 to 60 questions you have roughly a minute and a half to two minutes each. Use the mark-for-review flag on anything that makes you pause and come back once you have banked the easy marks. Read every scenario stem for the business constraint first — data residency, DLP, internal versus external audience — because AB-620 questions routinely bury the deciding detail in a subordinate clause rather than the headline requirement.

Case studies bundle several questions around one Copilot Studio scenario, and once you move past a case you generally cannot return to it, so answer everything inside a case fully before advancing. Remember the score is scaled: you need 700 out of 1000, not a perfect run, so an unfamiliar configuration is not a disaster. Flag it, make your best call, and keep moving.

Frequently asked

AB-620 FAQs

How hard is the AB-620 exam?

AB-620 is harder than it looks from the low-code label, because it tests judgement under business constraints rather than just tool familiarity. Expect a scenario naming a data-residency rule, a DLP policy, or an external-audience requirement that rules out an otherwise sensible answer. If the platform is new to you, budget extra hands-on time to practise topics, flows, and Dataverse together.

How long should I study for AB-620?

The six-week plan on this page is a practical starting point if you already work in Copilot Studio or the wider Power Platform. Extend it when Dataverse, Power Fx, and Microsoft Foundry integration are all new to you at once. Use your domain-level practice results to decide when to add or repeat a week.

Do I need AI-901 before AB-620?

AI-901 is not a formal prerequisite, but Microsoft's own certification path lists it as the current fundamentals route into AB-620. If generative AI concepts are new to you, sitting AI-901 first builds vocabulary the associate exam assumes you already have. If you already build agents or automations in the Power Platform, you can go straight to AB-620.

Is AB-620 the same as AI-103?

No. Microsoft's AB-620 audience profile expects familiarity with Microsoft Foundry alongside Copilot Studio, while AI-103 assesses building on Foundry itself. They are separate credentials, and many teams hold both.

What is the passing score for AB-620, and does it expire?

You need 700 out of 1000 to pass, on a scaled score rather than a raw percentage, so it does not map to a fixed number of correct answers. Like other Microsoft Associate certifications, AB-620 also expires annually, with a free online renewal assessment on Microsoft Learn that opens in the six-month window before your expiration date.

How much does AB-620 cost and can I retake it if I fail?

Exam pricing varies by country, so check Microsoft's certification page for the fee where you live rather than trusting a figure you read elsewhere. If you do not pass, the first retake is allowed after 24 hours, the second and third each require a 14-day wait, and Microsoft caps retakes at five attempts per rolling 12-month period. Each attempt needs a new booking.
