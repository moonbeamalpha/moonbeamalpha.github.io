Before you start

A few useful answers.

Is Ask Aura included in the free app?

Ask Aura Preview is available to Pro members. Azure Mastery is free to download, with starter questions for each supported exam. You can compare the access options in the app before buying.

Does Ask Aura use generative AI in this preview?

Generative coaching and explanations are not enabled in this preview. Aura starts with reviewed study-guide sections, terminology, question explanations and your on-device Exam IQ priorities. Check the cited source when accuracy matters.

Can I use Ask Aura offline?

The preview starts with bundled study material and on-device study priorities. Optional Microsoft Learn lookups need an internet connection and are off by default.

What happens to my conversations?

Saved Ask Aura conversations stay on this device and are excluded from app cloud sync and backups. Temporary chats are not saved. If you enable Microsoft Learn lookups, Microsoft receives only a public topic name or documentation address, not your message, answers or study progress.
