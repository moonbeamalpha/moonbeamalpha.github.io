The exam

What is the PL-300 exam?

PL-300 is the Microsoft Certified: Power BI Data Analyst Associate exam — the credential hiring managers expect for "Power BI Developer" or "Data Analyst" roles. It validates that you can deliver actionable insights end-to-end with Power BI, from cleaning raw data through to governed dashboards. PL-300 pairs naturally with DP-900 on the analyst track.

PL-300 is hands-on and tool-aware: expect scenario questions that show a Power Query step or a DAX measure and ask you to predict the result. Across the outline, you'll cover:

  • Connecting to and cleaning data from heterogeneous sources with Power Query (M)
  • Designing a star-schema model with DAX calculations and time intelligence
  • Building effective visualisations — the right visual choices, drill paths, and AI visuals
  • Operating Power BI at scale: workspaces, deployment pipelines, gateways, refresh schedules, RLS / OLS, and Microsoft Purview sensitivity labels

Common traps

Where PL-300 candidates slip

Four recurring misconceptions that trip up otherwise well-prepared PL-300 candidates, grounded in the current skills outline.

Reference and Duplicate look identical, but only one keeps a live link

Both queries start from an existing one, but only Reference stays linked to its source step as that step changes.

  • The exam is testing whether you know Reference stays linked while Duplicate freezes a snapshot at that point.
  • Trace whether the scenario needs several queries to update together before choosing Reference over Duplicate.

DirectQuery changes what a measure can and can't do

Switching a table to DirectQuery changes which DAX patterns work and how a calculated column behaves at query time.

  • The exam is testing whether you know DirectQuery changes what a calculated column can do, beyond changing speed.
  • Check the storage mode named in the scenario before assuming a calculated column behaves as it would in Import.

A measure and a calculated column don't share the same context

A calculated column is fixed per row at refresh, while a measure recalculates in whatever filter context a visual applies.

  • The exam is testing whether you can tell row context apart from filter context in a DAX scenario.
  • Pick a measure whenever the value should react to slicers, filters, or the current visual.

Object-level security is not the same control as row-level security

Row-level security filters which rows a user sees, while object-level security hides an entire table or column outright.

  • The exam is testing whether you'd pick object-level security specifically to hide a whole column, the stronger control than row filtering.
  • Reach for object-level security whenever the scenario says hide a column or table completely, not restrict rows.

6-week study plan

Suggested PL-300 study plan

Build from data preparation and modelling to reports, performance and security. Follow these six weeks of study blocks, finishing with focused review and rehearsal.

  1. Connect to data

    • Explore SQL Server, Excel, Fabric and OData sources.
    • Compare Direct Lake, DirectQuery and Import.
    • Review parameters and Power Query Editor.

  2. Transform with Power Query

    • Profile columns and manage data types.
    • Practise splitting, merging and pivoting.
    • Convert JSON or XML and build fact and dimension tables.

  3. Query design

    • Compare reference and duplicate queries.
    • Practise merge and append.
    • Review Formula.Firewall and query folding.

  4. Models and DAX

    • Design star schemas, relationships and role-playing dimensions.
    • Compare calculated columns with measures.
    • Practise time intelligence and USERELATIONSHIP.

  5. Choose visuals

    • Match chart and map types to reporting needs.
    • Review KPIs, gauges and treemaps.
    • Compare decomposition trees and key influencers.

  6. Report interaction

    • Configure drill-through, drill-down and bookmarks.
    • Build tooltip pages and synced slicers.
    • Review filters and what-if parameters.

  7. Accessible report design

    • Explore AI visuals, Q&A and Smart Narrative.
    • Use custom format strings, conditional formatting and themes.
    • Review accessibility choices.

  8. Reports and performance

    • Compare paginated and Power BI reports.
    • Design mobile layouts.
    • Use Performance Analyzer and DAX Studio to investigate slow models and visuals.

  9. Publish and manage

    • Compare workspace roles, apps and direct sharing.
    • Review deployment pipelines.
    • Configure gateways and refresh.

  10. Secure the data

    • Compare static and dynamic row-level security.
    • Review object-level security and sensitivity labels.
    • Explore Purview integration and tenant settings.

  11. Target weaker topics

    • Run Focus Weak Spots sessions.
    • Balance revision across the domains.
    • Revisit missed scenarios and explanations.

  12. Timed rehearsal

    • Complete two 100-minute Exam Simulator sessions.
    • Review each run carefully.
    • Plan further study based on recurring mistakes.

Frequently asked

PL-300 FAQs

PL-300 vs DP-900 — which should I take first?

Take DP-900 first if relational vs non-relational data, transactional vs analytical workloads, or Azure's SQL family aren't familiar yet. PL-300 assumes you already know the difference when it asks about DirectLake vs DirectQuery vs Import or Fabric semantic models. Skip DP-900 if you already do analyst work day-to-day.

PL-300 vs DP-300 — different roles?

Different angles on the data stack. PL-300 is the analyst-side cert: Power Query M, DAX, visualisations, governance and sharing. DP-300 is the operational DBA cert: HA/DR, performance tuning, security, and automation for Azure SQL. Larger teams often split the two roles.

Are there formal prerequisites for PL-300?

No mandatory prior exam, but Microsoft's audience profile expects proficiency with Power Query and DAX, plus comfort working with stakeholders on requirements and with data engineers on sourcing. Candidates without hands-on Power BI experience usually need a longer run-up, even though nothing blocks booking directly.

What's the PL-300 exam format like?

PL-300 sits in Microsoft's 40–60 question Associate band, with formats varying by sitting. Azure Mastery's bank weights single-answer and dropdown-select items heaviest, reflecting how often the exam asks you to predict a DAX result or Power Query step, alongside multi-select, drag-to-match, and case-study questions.

Does PL-300 prep need a live internet connection?

No. Every part of PL-300 practice, including the Exam IQ prediction, runs on your device rather than a server, so full sessions work on a delayed train or a long-haul flight. No account is needed, and data stays put unless you opt into private iCloud sync.

Yes. The app is free to download, with a free allowance of PL-300 questions so you can try every feature. The full bank of 378 PL-300 practice questions unlocks with a one-time exam-pack purchase, or unlock every exam with a subscription or lifetime upgrade.

If I don't pass PL-300, when can I try again?

Not immediately, and each attempt needs its own voucher.

  • First retake: after 24 hours.
  • Second and third retakes: a 14-day wait each.
  • Cap: five attempts per rolling 12 months.
Will my PL-300 badge lapse if I don't renew?

Yes. Associate certifications including PL-300 expire annually. Renewal is a free 25–30 question assessment on Microsoft Learn within six months of your expiry date. Fundamentals certs like AZ-900 are different — those never expire.

What's the going rate for a PL-300 exam attempt?

The PL-300 voucher is USD $165 in the US, or around £128 in the UK — pricing varies by region. Microsoft occasionally runs free-voucher promotions around events like Build or Ignite, so check your Learn profile first.
