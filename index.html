            AZ-104

            Question 1 of 3

            Virtual Machine Scale Sets · Single answer

            A VM scale set is configured with a scale-out rule: when average CPU > 70% for 10 minutes, increase instance count by 20%. The current instance count is 5 and maximum is 10. Average CPU reaches 80% for 12 minutes. How many instances will be running after the scale-out action?

            • 5Leaving the count at 5 would mean no scale-out happened, but the rule's condition (average CPU above 70% for 10 minutes) is satisfied at 80% over 12 minutes, so the engine does add capacity.
            • 6A 20% increase on the current 5 instances equals 1 additional instance, and 5 + 1 = 6 stays under the configured maximum of 10, so autoscale provisions exactly 6 instances.
            • 10Reaching 10 would require the percentage increase to exceed the maximum cap, but a 20% bump from 5 only yields 6, so the maximum of 10 is never approached by this single action.
            • 7Arriving at 7 implies adding 2 instances, but 20% of 5 rounds to a single instance, so the engine adds 1 rather than 2.

            AZ-104

            Question 2 of 3

            Storage Redundancy and Failover · Single answer

            You need the lowest-cost storage redundancy option that copies critical data to a secondary Azure region for disaster recovery. Applications do not need to read from the secondary region unless a failover occurs. Which option should you choose?

            • Locally Redundant Storage (LRS)LRS keeps copies within one datacenter and provides no secondary-region copy.
            • Zone-Redundant Storage (ZRS)ZRS spreads copies across availability zones in the primary region but does not copy data to a secondary region.
            • Geo-Redundant Storage (GRS)GRS is the lowest-cost listed option that copies data to a secondary region when applications do not require direct secondary read access.
            • Read-Access Geo-Redundant Storage (RA-GRS)RA-GRS uses the same geo-replication and adds a readable secondary endpoint, which costs more and is not required by this scenario.

            AZ-104

            Question 3 of 3

            Azure Monitor Alerts · Single answer

            Operations needs an email when a production VM stays above 90% CPU for 5 minutes. The alert should be near real time and should not require writing KQL unless necessary. Which Azure Monitor design is most appropriate?

            • A Log Analytics query alert paired with a runbook-driven notification workflowLog query alerts run KQL against ingested logs in a Log Analytics workspace, adding ingestion latency plus query authoring, and chaining a runbook adds orchestration overhead the scenario explicitly wants to avoid for a simple email.
            • A Metric alert rule with an action group containing an email actionPercentage CPU is a native VM platform metric, so a metric alert evaluates it directly at near-real-time frequency with no KQL or log ingestion, and an attached action group with an email action delivers the notification when the 90% threshold holds for 5 minutes.
            • Azure Advisor recommendations reviewed manually by operations staffAdvisor surfaces periodic optimization and right-sizing recommendations on a batch cadence; it does not evaluate a live CPU threshold or send threshold-breach notifications.
            • Azure Service Health alerts that only report Azure platform incidentsService Health reports Azure platform incidents and planned maintenance affecting the service itself, not customer workload metrics like a single VM's CPU utilization.

            AZ-900

            Question 1 of 3

            Cloud Models · Single answer

            A company wants to migrate a line-of-business application to Azure without changing how it is deployed. The IT team must keep control of the guest operating system, install a custom monitoring agent, and manage application patching themselves. Which cloud service model best fits this requirement?

            • Platform as a Service (PaaS)PaaS has the provider manage the operating system and platform runtime, so it does not give the team guest-OS control to install an OS-level monitoring agent. The customer still maintains its application code, updates, configuration and data; application patching alone does not distinguish PaaS from IaaS.
            • Function as a Service (FaaS)A managed function platform handles the underlying operating system and runtime. It does not provide the guest-OS control required to install the monitoring agent or preserve this application’s existing VM deployment model.
            • Infrastructure as a Service (IaaS)Infrastructure as a Service provisions virtual machines where the customer retains full control of the guest operating system, can install custom software such as a monitoring agent, and remains responsible for application patching, which matches a lift-and-shift migration that keeps the existing deployment model unchanged.
            • Software as a Service (SaaS)Software as a Service delivers a finished, vendor-operated application such as Microsoft 365; there is no guest OS to control, no place to install custom agents, and no application patching for the customer to own, so it cannot host a migrated line-of-business app.

            AZ-900

            Question 2 of 3

            Consumption-Based Model · Single answer

            Before approving a new Azure deployment, a project manager wants an estimate of the expected monthly cost for selected services, regions, and sizes. Which tool should be used?

            • Azure MonitorAzure Monitor collects metrics, logs, and telemetry from resources that are already running so you can observe health and performance; it has no facility for forecasting the price of a configuration that has not yet been deployed.
            • Azure Pricing CalculatorThe Azure Pricing Calculator is the web-based estimation tool built for exactly this pre-deployment task: you add services, then set region, SKU/tier, instance size, operating system, and usage hours, and it returns an estimated monthly cost using per-unit retail prices that update as you change parameters.
            • Microsoft Defender for CloudMicrosoft Defender for Cloud evaluates security posture, surfaces a secure score, and protects workloads against threats; it produces no cost estimate for a planned set of services and sizes.
            • Azure Resource GraphAzure Resource Graph runs fast queries across the inventory of resources that already exist in your subscriptions; it reports on deployed assets rather than projecting the monthly price of a proposed configuration.

            AZ-900

            Question 3 of 3

            Azure Database Services (SQL, Cosmos DB, MySQL, PostgreSQL) · Single answer

            A team wants a managed relational database for a new Azure-hosted application. They want Microsoft to handle operating system patching, database engine updates, backups, and built-in high availability. Which service best fits?

            • Azure SQL DatabaseThis is a fully managed PaaS relational database where Microsoft operates the underlying infrastructure, applies OS and SQL Server engine patches, takes automated backups, and provides built-in high availability, so the team never administers servers. It also offers vCore and DTU purchasing models plus serverless and Hyperscale tiers to match workload needs.
            • SQL Server on Azure Virtual MachinesThis is an IaaS offering where the customer remains responsible for the guest operating system, including applying OS updates and SQL Server patches, plus configuring backups and high availability themselves. That operational burden is exactly what the team wants Microsoft to handle, so it fails the managed requirement.
            • Azure Database Migration ServiceThis is a migration tool used to move data into Azure data platforms, not a database engine that hosts and serves a running application. It performs a one-time or staged data transfer and is not designed to be the long-term home for the application's relational data.
            • Azure Virtual DesktopThis is a desktop and application virtualization service that delivers Windows session hosts to end users, not a database platform. It provides no relational database engine, automated backups, or database high availability, so it cannot support the application's data tier.

            Frequently asked

            Questions, answered

            Is Azure Mastery free?

            Azure Mastery is free to download, with at least 50 practice questions per supported exam, written explanations and offline practice. Individual full exam banks are one-time purchases with no subscription required for the bank. Pro adds every bank and advanced study tools. No account is needed; local prices are confirmed in the app before purchase.

            Which Microsoft certifications does Azure Mastery cover?

            Azure Mastery covers 30 Microsoft certification exams: AZ-900, AZ-104, AZ-305, AZ-400, AZ-700, AI-901, AI-103, AI-200, AI-300, AI-500, AB-100, AB-410, AB-620, AB-650, AB-731, AB-900, DP-900, DP-300, DP-700, DP-750, DP-800, SC-900, SC-100, SC-200, SC-300, SC-500, PL-300, PL-900, GH-900, and GH-300. The app spans Azure infrastructure, AI engineering, data, security and compliance, Microsoft 365 Copilot administration, AI transformation leadership, SQL AI development, agentic AI architecture, multi-agent AI engineering, and Power BI roles.

            How does the Exam IQ score work?

            Exam IQ uses a CoreML model on your device to estimate your exam-day score and a confidence range. It considers your accuracy in each domain, question coverage, mastery, consistency, and how recently you practised. The range narrows as you answer more questions. Your answers stay on your device.

            More questions about the app
            What is Ask Aura?

            Ask Aura Preview is the private Pro study companion in Azure Mastery 2.0. It starts with reviewed material for your current exam, shows source cards behind its answers, can quiz you, turn Exam IQ priorities into a focused study session, and bring saved takeaways back when they are due. Saved conversations stay on your device, and temporary chats are not saved.

            Does Azure Mastery work offline?

            Yes. Questions, Exam IQ score prediction, adaptive study plans, written Answer Coach guidance, and Ask Aura's bundled study material work offline. Optional Microsoft Learn lookups need a connection and stay off until you enable them. If you choose to sync, it uses your private iCloud account. Azure Mastery has no server for your study data and does not track how you use the app.

            Does Azure Mastery support iPad and Apple Watch?

            Yes. Azure Mastery is a native SwiftUI app for iPhone and iPad, with Stage Manager support and layouts for larger iPad screens. The Apple Watch companion shows your daily streak and XP. Live Activities show your study timer on the Lock Screen and Dynamic Island.

            How is Azure Mastery different from other Microsoft exam prep apps?

            Azure Mastery helps you know when you're ready and what to practise next. It compares your predicted score with Microsoft's pass threshold and estimates your ability in each exam domain, so you can see which areas need work. Spaced repetition helps you revisit topics you're starting to forget. The machine learning runs on your device without tracking your activity.

            What kinds of practice questions are included?

            The app includes 12,700+ practice questions across 30 Microsoft exams. Azure Mastery uses nine interactive, exam-style formats including multiple choice, multi-select, drag-and-drop ordering, hotspot, and case studies; the live exam's exact interface and item mix are controlled by Microsoft and may differ. Every question includes the correct reasoning and an explanation, with option-by-option rationale where available. Choose whether explanations appear after each question or at the end of a practice test, then jump straight to missed answers; Answer Coach keeps its session notes ready when you revisit.

            Who makes Azure Mastery?

            Azure Mastery is published by Moonbeam Alpha Ltd, an independent iOS app studio focused on certification preparation. The app is not affiliated with or endorsed by Microsoft. Read more on the About page.
