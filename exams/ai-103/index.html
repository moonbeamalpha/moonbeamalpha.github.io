The exam

What is the AI-103 exam?

AI-103 is the exam for the Microsoft Certified: Azure AI Apps and Agents Developer Associate credential. It is aimed at Azure AI engineers who build, manage, and deploy agents and AI solutions with Microsoft Foundry. The exam expects practical Python experience and familiarity with general AI, generative AI, and Azure services.

AI-103 is hands-on and SDK-aware. It validates that you can plan and manage Azure AI solutions; implement generative AI and agentic solutions; build computer vision solutions; implement text analysis and speech workflows; and create information-extraction and retrieval pipelines. Expect scenarios involving Python, Foundry projects, models, agents, Azure AI Search, Content Understanding, security, evaluation, and observability.

The heaviest-weighted domain, and the most hands-on. Common traps

Where AI-103 candidates slip

Five recurring misconceptions that trip up otherwise well-prepared AI-103 candidates, grounded in the current skills outline.

Right-sizing the model, not maximising it

AI-103 scenarios often describe a task a small or code-optimised model handles fine, then list a large multimodal model as a tempting option. The exam rewards matching model class to task — latency, cost, and context needs — not defaulting to the biggest model available. Treat "which model" questions as a sizing problem first.

RAG is not fine-tuning

Retrieval-augmented generation grounds a model's answers in your own content at query time; it doesn't change the model's weights. Candidates sometimes reach for RAG when a scenario actually needs model customisation, or the reverse. If the requirement is "answer from our current documents," that's retrieval, not training.

One agent with tools vs. orchestrated agents

A single agent equipped with several tools and a multi-agent solution that delegates subtasks to separate agents solve different shapes of problem. AI-103 tests whether you can tell when a task needs one agent calling functions versus an orchestrator handing work to specialised agents with their own memory and scope.

Filters, evaluators, and governance aren't the same control

Content filters block unsafe output at runtime. Evaluators measure quality and safety offline, after the fact. Governance controls — approval workflows, oversight modes, tool-access limits — constrain what an agent is allowed to do in the first place. Responsible-AI questions expect you to place a described control in the right one of these three categories.

Content Understanding is a pipeline, not just OCR

Extracting text from a scanned document is one small piece of what Content Understanding does. The exam also tests structured and Markdown output generation, multimodal analysis across documents, images, audio and video, and connecting that output directly into a RAG or agent pipeline — treating it as "just OCR" misses most of what's tested.

6-week study plan

Suggested AI-103 study plan

Most candidates pass AI-103 after four to eight weeks of focused study, depending on prior Azure experience. The six-week plan below maps onto the five AI-103 domains, Azure Mastery's adaptive sessions, and the in-app exam simulator. Adjust pace to taste — the readiness gauge tells you when you're done, not the calendar.

  1. Plan, manage, and build generative AI

    • Week 1: Plan and manage Azure AI solutions — Foundry services, models, deployment, CI/CD, monitoring, security, cost, and responsible AI.
    • Week 2: Implement generative and agentic solutions — RAG, Foundry SDKs, tools, memory, multi-agent orchestration, safeguards, evaluation, and tracing.

  2. Computer vision and text analysis

    • Week 3: Computer vision — image and video generation and editing, multimodal understanding, Content Understanding, accessibility outputs, and visual safety.
    • Week 4: Text analysis and speech — extraction, summaries, sentiment, translation, speech-to-text, text-to-speech, and audio reasoning.

  3. Information extraction, sharpen, simulate

    • Week 5: Information extraction — multimodal ingestion, semantic/hybrid/vector search, OCR, RAG pipelines, and structured outputs with Content Understanding.
    • Week 6: Run Focus Weak Spots every morning, then two end-to-end Exam Simulator runs at full 100-minute length. Schedule the exam when readiness gauge is 750+ with reasonable confidence.

Frequently asked

AI-103 FAQs

How much does the AI-103 exam cost?

The AI-103 voucher costs USD $165 in the United States (around £128 in the UK; regional pricing varies). Because AI-103 is a role-based Associate exam rather than a Fundamentals-tier one, Microsoft rarely bundles it into free promotional vouchers — watch for occasional offers around Microsoft Build or Microsoft Ignite instead. Renewal itself is free.

Does the AI-103 certification expire?

Yes — like every Microsoft Associate certification, AI-103 expires annually. Renewal is a free, 25–30 question assessment on Microsoft Learn, available in the six-month window before expiry, and it's scoped to whatever changed in the outline since you last certified. AI-901, the Fundamentals-tier exam, doesn't expire — only role-based certifications like AI-103 do.

What is the AI-103 retake policy if I fail?

You can retake AI-103 24 hours after a failed first attempt; the second and third retakes each require a 14-day wait. Microsoft allows a maximum of five attempts in any rolling 12 months, and every attempt needs its own voucher.

What does the AI-103 exam format look like?

Like most Microsoft Certification exams, AI-103 has 40–60 questions in a mix of formats, with the exact timing confirmed at registration. It runs as a 100-minute session (120 minutes with the seat time Microsoft allows for exam admin), taken online with a proctor or at a test centre, and scored out of 1000 with a 700 pass mark. In Azure Mastery's AI-103 bank you'll practise several of those formats yourself — single-answer and multi-select multiple choice, ordering and matching items, and a small number of linked case studies.

How long should I study for AI-103?

Plan for several weeks of focused study if you already write Python and have touched Azure AI services before; extend that if Microsoft Foundry, agents, or multimodal AI are new territory. The exam expects working familiarity across five distinct domains, so breadth of practice matters as much as depth in any one area. Azure Mastery's readiness gauge helps you judge when you've closed that gap.

AI-103 vs AI-102 — different roles?

AI-102 retired on 30 June 2026. AI-103 replaced it as the current Azure AI Apps and Agents Developer Associate exam, and it reflects how far the underlying platform has shifted toward Microsoft Foundry, agentic patterns, and multimodal content — not just a renamed version of the old outline.

AI-103 vs AI-901 — which should I take first?

Take AI-901 first if generative AI and Microsoft Foundry are unfamiliar concepts — it's the Fundamentals exam and assumes no coding. AI-103 assumes you can already write Python and expects hands-on familiarity with Foundry projects, agent tools, retrieval, and evaluation. Candidates with existing development experience sometimes skip AI-901 and go straight to AI-103.

Do I need real Foundry or Python experience before I start?

Not to begin studying, but AI-103 is written for candidates who already develop with Python and have touched Azure services — it isn't an intro-to-AI exam. If you're newer to development, working through Microsoft Foundry's own quickstarts alongside Azure Mastery's practice questions will close that gap faster than question practice alone.
