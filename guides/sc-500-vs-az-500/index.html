SC-500 vs AZ-500: what changed when Microsoft retired AZ-500

AZ-500 retired on 31 August 2026. See exactly what SC-500 kept, what it added, and what happens to an AZ-500 credential you already hold.

Updated 4 September 2026 · ~9 min read

Quick answer

SC-500 or AZ-500: the short version

This isn't really a choice any more. AZ-500 retired on 31 August 2026, so SC-500 is the only cloud-security Associate exam you can currently book. What's worth understanding is what changed, and what an existing AZ-500 credential is still worth.

New to cloud security? Sit SC-500

SC-500 (Microsoft Certified: Cloud and AI Security Engineer Associate) is the current, bookable exam for anyone starting a cloud security career today. It keeps the core Azure security-engineering content AZ-500 tested and adds a full domain of AI-workload security that AZ-500 never covered.

Already hold AZ-500? It stays on your transcript

Passing AZ-500 before its retirement date remains valid — Microsoft does not revoke certifications when the underlying exam retires. What it does mean is that AZ-500 itself can no longer be renewed. See "If you hold AZ-500" below for what that means in practice and how much of your existing knowledge carries straight over.

Both exams lead to a "Microsoft Certified" Associate credential in cloud security; the difference below is entirely about scope and timing, not prestige.

What SC-500 actually tests

What SC-500 actually tests

SC-500 covers the same operational ground AZ-500 did — identity, networking, compute, storage, and Defender for Cloud — and folds AI-workload security into the compute domain rather than treating it as an afterthought.

SC-500 skills measured (outline effective 13 May 2026)
DomainWeight
Manage identity, access & governance20–25%
Secure storage, databases & networking25–30%
Secure compute20–25%
Manage & monitor security posture20–25%

Identity and governance covers Privileged Identity Management, Conditional Access, and Key Vault, alongside Azure Policy and RBAC remediation. The largest domain, storage/databases/networking, is largely continuous with AZ-500's networking and storage material: NSGs, Private Link, Azure Firewall, Defender for Storage and Databases. Secure compute is where SC-500 diverges hardest from AZ-500: alongside disk encryption, Bastion, and Defender for Servers and Containers, it adds a dedicated AI-security skill group covering Microsoft Entra Agent ID, Defender for AI Services, Foundry guardrails, AI Gateway in API Management, and Purview DSPM for Copilot. Posture management rolls up Defender CSPM, multicloud connectors, Microsoft Sentinel ingestion, and Microsoft Security Copilot into one domain rather than one oversized 30–35% block.

What AZ-500 tested

What AZ-500 tested (retired 31 August 2026)

Kept here as a reference for anyone comparing what they already studied against SC-500's current outline, not as an active exam guide.

AZ-500 skills measured (final outline, effective 22 January 2026)
DomainWeight
Secure identity & access15–20%
Secure networking20–25%
Secure compute, storage & databases20–25%
Secure Azure using Defender for Cloud & Sentinel30–35%

Identity and access covered role assignments, PIM, Conditional Access, and Microsoft Entra app registrations and managed identities. Networking covered NSGs, Virtual Network Manager, Virtual WAN, private access patterns, and Azure Firewall. Compute, storage, and databases covered VM and AKS security, storage access control, and Azure SQL protections including Transparent Data Encryption. The largest domain by far was Defender for Cloud and Sentinel: governance policy, Secure Score remediation, threat protection plans, and hands-on Sentinel configuration including data connectors and analytics rules. Three of these four domains map closely onto SC-500's current outline; the fourth is where SC-500 now spends part of its weight on AI security instead.

Prerequisite question

Is there a prerequisite for SC-500?

No formal one. SC-500 doesn't require another certification before you can book it, in the same way AZ-500 never did. Microsoft's own guidance recommends practical experience administering Azure and hybrid environments and strong familiarity with Microsoft Entra ID before attempting it, and Azure Mastery's own certification pathing lists AZ-104 as a recommended (not required) lead-in, exactly as it did for AZ-500.

SC-500 also does not currently unlock anything further up the security track on its own. Microsoft's published prerequisite guidance for SC-100 (Cybersecurity Architect Expert) does not list SC-500 as an accepted route as of this guide's last update — check the official SC-100 requirements directly before assuming otherwise, since Microsoft updates prerequisite lists independently of exam retirements.

If you're deciding whether SC-900 (Security, Compliance, and Identity Fundamentals) is worth sitting first: it's optional conceptual groundwork, exactly as it was for AZ-500, and mainly useful if security terminology itself — not just Azure — is new to you.

Career value

How SC-500 changes what the credential signals

AZ-500 signalled "Cloud Security Engineer" or "Azure Security Specialist" — someone who could lock down identity, networking, compute, and storage, and run day-to-day operations in Defender for Cloud and Sentinel. SC-500 signals the same operational competence, plus a claim AZ-500 never made: that you can extend those same controls to the AI systems now running inside the organisation, from Copilot agents to Foundry-hosted models.

That AI-security scope is the reason SC-500 exists rather than a straight AZ-500 renewal cycle. As organisations put Copilot and custom agents into production, "who governs what an AI agent can access" became a real operational question that AZ-500's outline had no domain to answer. Hiring managers posting "Cloud Security Engineer" or "Cloud and AI Security" roles in 2026 are increasingly asking for that AI-specific coverage explicitly.

Neither certification guarantees a role or a pay rise on its own. What SC-500 does is keep the underlying credential current and renewable, which AZ-500 — through no fault of the people who hold it — can no longer do.

If you hold AZ-500

What happens to an AZ-500 credential you already hold

Your certification stays on your Microsoft transcript exactly as it is. Microsoft does not retroactively remove or downgrade a credential because the exam that produced it has since retired — the "Microsoft Certified: Azure Security Engineer Associate" line on your record is permanent proof of what you passed and when.

What changes is renewal. Microsoft's own guidance states that renewal assessments are no longer available once a certification's exam has retired, so AZ-500 itself has no ongoing free annual renewal path any more. The entry stays on your transcript as a record of what you passed and when, but there is no mechanism left to formally refresh it against a current skills outline.

The practical route for staying current is SC-500. Three of AZ-500's four domains — identity and access, networking, and compute/storage/databases — map closely onto SC-500's identity, storage/database/networking, and compute domains, so an AZ-500 holder is not starting from zero. The genuinely new material sits in two places: the AI-security skill group inside Secure Compute (Entra Agent ID, Defender for AI Services, Foundry guardrails, AI Gateway, Purview DSPM for Copilot), and Microsoft Security Copilot inside posture management. Everything else is a change of emphasis and consolidation, not new content to learn from scratch.

Frequently asked

SC-500 vs AZ-500 FAQs

Is AZ-500 still a valid certification?

Yes. If you passed AZ-500 before it retired, the certification stays on your Microsoft transcript. Microsoft does not revoke or downgrade a credential because the exam behind it has retired. What changes is that you can no longer renew it through AZ-500 itself, because renewal assessments stop being offered once an exam retires.

Can I still book the AZ-500 exam?

No. AZ-500 retired on 31 August 2026 and is no longer available to schedule. If you are starting a cloud security career now, SC-500 is the current path; there is no way to sit AZ-500 as a new candidate.

What's actually new in SC-500 that wasn't in AZ-500?

AI security. SC-500's Secure Compute domain adds a full skill group on securing Microsoft Copilot and AI agents: Microsoft Entra Agent ID conditional access and blast-radius analysis, Defender for AI Services, Foundry guardrails, AI Gateway in Azure API Management, and Microsoft Purview Data Security Posture Management for Copilot. None of that existed in AZ-500's outline. SC-500 also adds Microsoft Security Copilot workspace and plugin management to its posture-monitoring domain.

Do I need to retake anything if I already have AZ-500?

There is no requirement to retake anything; your AZ-500 credential remains on your transcript as evidence of what you passed. But because AZ-500 can no longer be renewed, if you want a current, renewable Associate-level cloud security credential going forward, SC-500 is the exam that does that job now.

Is SC-500 harder than AZ-500 was?

They are comparably demanding overall, but the difficulty is distributed differently. AZ-500 concentrated 30 to 35% of its weight in Defender for Cloud and Microsoft Sentinel, including hands-on KQL query writing. SC-500 spreads that content more evenly across four domains and trades some of that Sentinel depth for breadth into AI-specific security controls, which is unfamiliar territory for most Azure administrators moving across from AZ-500.

Does SC-500 count as a prerequisite for SC-100?

Not currently. Microsoft's published prerequisite guidance for SC-100 (Cybersecurity Architect Expert) does not list SC-500 as an accepted route as of this guide's last update. Check the official SC-100 requirements before assuming SC-500 alone will satisfy them.
