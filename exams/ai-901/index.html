The exam

What is the AI-901 exam?

AI-901 is the current exam for the Microsoft Certified: Azure AI Fundamentals credential. It replaced AI-900, which retired on 30 June 2026. AI-901 is intended for people starting to work with AI solutions on Azure, including aspiring junior developers who are beginning to add AI capabilities to applications.

The current exam combines conceptual knowledge with foundational technical skills. You should understand core cloud concepts, Azure resources, common AI capabilities, responsible AI, and how client applications consume models and services. You also need to understand Python syntax and code examples that call AI models and services, and be able to use Microsoft Foundry to deploy models and implement single-agent solutions.

The English AI-901 exam was updated on 15 April 2026. Azure Mastery's question bank covers the current outline, with five granular study tags rolled up to Microsoft's two assessed areas. Read the official Microsoft exam page.

AI-901 exam objectives

Microsoft groups the current exam into two assessed areas. The summaries below are paraphrased from the official exam page; Azure Mastery's finer topic tags help you pinpoint weak spots inside each area. Microsoft's stated audience profile assumes conceptual knowledge of Azure AI solutions, familiarity with Azure resources, and comfort with Python coding syntax and programming techniques — you're not expected to be a working developer, but you should be able to read code, not just recognise service names.

Identify AI concepts and capabilities40–45%

Explore key topics

The knowledge-heavy half of the exam, testing whether you can recognise the right AI approach before you touch Foundry. Responsible AI covers Microsoft's six principles — fairness, reliability and safety, privacy and security, inclusiveness, transparency, and accountability — and how each shows up in a solution's design. AI model components and configurations cover how generative AI models work under the hood, choosing an appropriate model based on its capabilities, and picking sensible deployment options and configuration parameters. AI workloads is the broadest topic: recognising scenarios for generative and agentic AI, text analysis, speech, computer vision, and information extraction; naming core text-analysis techniques like keyword extraction, entity detection, sentiment analysis, and summarisation; identifying speech recognition and speech synthesis features; spotting computer vision and image-generation model capabilities; and matching extraction techniques to text, image, audio, and video sources. Around 16–27 questions.

Implement AI solutions by using Microsoft Foundry55–60%

Explore key topics

The larger, hands-on half. Generative AI apps and agents cover writing effective system and user prompts, deploying and testing a model directly in the Foundry portal, building a lightweight chat client with the Foundry SDK, and creating and testing a single-agent solution with its own client application. Text and speech solutions cover building a lightweight app with text analysis, responding to spoken prompts through a deployed multimodal model, and using Azure Speech in Foundry Tools. Computer vision and image generation cover interpreting visual input through a deployed multimodal model, generating new visual outputs, and building a lightweight vision-enabled app. Information extraction covers pulling structured data out of documents, forms, images, audio, and video with Azure Content Understanding in Foundry Tools, then wiring those outputs into a lightweight application. You should be comfortable reading foundational Python examples across every topic here — the exam expects you to interpret short SDK snippets, not just recognise service names. Around 22–36 questions.

6-week study plan

Suggested AI-901 study plan

Build AI foundations, then practise with Foundry models, agents and multimodal tools. Connect each Python example to its purpose as you follow this six-week route.

  1. AI models and responsibility

    • Review the six responsible AI principles.
    • Understand generative models and compare their capabilities.
    • Explore deployment options and configuration parameters.

  2. Recognise AI workloads

    • Compare generative, agentic, vision and speech workloads.
    • Review extraction, entities, sentiment and summarisation.
    • Revisit workload categories you find difficult to distinguish.

  3. Foundry models and agents

    • Write system and user prompts; deploy and test a model.
    • Build a lightweight chat client with the Foundry SDK.
    • Explore a single-agent solution and its client app.

  4. Text, speech and vision

    • Build text-analysis apps.
    • Explore spoken prompts and Azure Speech in Foundry Tools.
    • Interpret visual input and generate visual outputs.

  5. Information extraction

    • Extract structured data from documents, images, audio and video.
    • Connect Content Understanding outputs to a lightweight app.
    • Read Python examples and identify the Foundry resources they call.

  6. Review and rehearse

    • Use Domain Proficiency and Focus Weak Spots to target gaps.
    • Complete two timed, 45-minute Exam Simulator sessions.
    • Review mistakes across both assessed areas before planning further study.

AI-901 FAQs

How much does the AI-901 exam cost?

Microsoft prices AI-901 according to the country or region where the exam is proctored. Check the official scheduling page for the current local price before booking.

Does the AI-901 certification expire?

No. AI-901 earns the Microsoft Certified: Azure AI Fundamentals credential, and Microsoft Fundamentals certifications do not expire.

What is the AI-901 retake policy if I fail?

The first retake is allowed after 24 hours. Second and third retakes each require a 14-day wait. Microsoft caps retakes at five attempts per 12-month rolling period. Each attempt requires a new voucher purchase.

How long should I study for AI-901?

Allow several weeks for concepts plus hands-on practice. The current outline expects core cloud knowledge, familiarity with Azure resources, and an understanding of Python syntax and examples that call AI models and services. Azure Mastery's readiness gauge helps you decide when to schedule the exam.

AI-901 vs AI-900 — different exams?

AI-901 replaced AI-900 on 1 July 2026. AI-900 retired on 30 June 2026 and can no longer be scheduled. AI-901 remains the route to the Azure AI Fundamentals credential and adds a more implementation-oriented focus on Microsoft Foundry and Python examples.

What should I take after AI-901?

Choose the role-based exam that matches how you build agents. AI-103 covers code-first AI apps and agents with Python and Microsoft Foundry. AB-620 covers integrated agents built with Copilot Studio, Power Platform, and Microsoft 365. Both build on the foundations assessed by AI-901.
