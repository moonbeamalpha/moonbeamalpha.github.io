The exam

What is the DP-900 exam?

DP-900 is the Microsoft Certified: Azure Data Fundamentals credential — the data-literacy exam Microsoft points at anyone touching data in Azure without owning a database. It's pitched at candidates who already know what a spreadsheet and a database are but haven't had to reason about redundancy tiers, Cosmos DB APIs, or the split between a warehouse and a lake. Common audiences include data analysts about to step into Power BI work, software engineers crossing into a data role, and delivery leads who need to speak data architecture credibly in a design meeting.

The exam doesn't ask you to write SQL queries from scratch or design a star schema. It expects you to recognise scenarios: structured vs semi-structured vs unstructured data; OLTP vs OLAP workloads; the difference between Azure SQL Database, Azure SQL Managed Instance, and SQL Server on Azure VMs; when to reach for Azure Cosmos DB, Azure Blob Storage, or Azure Data Lake Storage Gen2; and how Microsoft Fabric's analytics surface fits with ingestion, streaming, and Power BI visualisation.

Common traps

Where DP-900 candidates slip

Recurring misconceptions that trip up otherwise well-prepared DP-900 candidates, grounded in the current skills outline.

OLTP and OLAP describe workloads, not products

Candidates often try to memorise "which Azure service is OLTP" and "which is OLAP" as a fixed list. OLTP and OLAP describe how data is used — many short transactions versus large aggregated reads — and the same underlying service family can support either shape depending on how it's configured. The exam wants you to classify a described workload by its access pattern, not recite a product-to-category lookup table.

Three SQL options solve overlapping but different problems

Azure SQL Database, Azure SQL Managed Instance, and SQL Server on Azure VMs all run SQL Server-compatible workloads, which tempts candidates into treating them as interchangeable. Database is the fully managed, cloud-native option; Managed Instance targets near-total instance-level compatibility for a lift-and-shift; SQL Server on a VM hands you the whole OS when you need something neither managed option supports. A scenario naming a specific compatibility or control requirement usually rules out two of the three.

A Cosmos DB API choice is a data-model choice, not a preference

Cosmos DB's NoSQL, MongoDB, Cassandra, Gremlin, and Table APIs aren't styling options on the same database — each is built around a different data model (document, wide-column, graph, key-value) and picking one commits you to that shape. A scenario describing relationships and traversals between entities is pointing at the Gremlin API; one describing existing MongoDB application code is pointing at the MongoDB API, regardless of which API "seems" more modern.

Microsoft Fabric and Azure Synapse Analytics aren't competitors in every question

Recent skills-outline updates expanded Microsoft Fabric's role, and candidates sometimes read every analytics question as "pick Fabric over Synapse." The two overlap in places, but a scenario can still legitimately point at Synapse-specific pipeline or dedicated-pool behaviour. Read what the scenario is actually asking about — ingestion, unified analytics experience, or a specific warehousing feature — rather than defaulting to whichever service was mentioned most recently in the course material.

Structured, semi-structured, and unstructured are about shape, not size

Candidates sometimes assume "unstructured" means "unimportant" or "small," when it just means the data doesn't fit a predefined schema — video files and free-text documents are unstructured regardless of size or business value. JSON and XML are semi-structured because they carry some organisational markers without a fixed schema. Getting this classification wrong cascades into picking the wrong storage service for a described file type.

DP-900 FAQs

Do I need database experience before sitting DP-900?

Very little is assumed. Microsoft doesn't expect database-administration experience or hands-on SQL — just basic familiarity with what a spreadsheet or database is, and a general sense of what "cloud" means. If you can describe why a company might store data in more than one place, you have enough of a starting point; the exam teaches the Azure-specific vocabulary as you study.

What does the DP-900 exam actually look like?

Microsoft's own guidance states 40–60 questions with formats that vary by sitting — single-answer multiple choice, multi-select, and scenario items are typical. Azure Mastery's DP-900 bank mirrors that mix: mostly single-answer multiple choice, a real share of scenario-based and multi-select questions, and a smaller run of drag-and-drop, drag-to-match, dropdown-select, and hotspot items, plus linked case studies — so you rehearse the format variety, not just one question shape.

DP-900 vs PL-900 — which should I take first?

They test different things and neither is a prerequisite for the other, so pick based on your role. DP-900 covers data concepts and Azure's data services — relational vs non-relational, analytics workloads, Power BI as a visualisation layer. PL-900 covers the low-code Power Platform itself — Power Apps, Power Automate, Dataverse, and Copilot Studio agents. A data analyst or engineer heading toward DP-300 or AI-300 should start with DP-900; a business user or maker heading toward PL-300 should start with PL-900. Many candidates who work across both simply sit them in either order.

What's the DP-900 exam fee, and does it vary by region?

The DP-900 voucher is USD $99 in the United States. Pricing varies by region — in the UK it's typically around £77. Microsoft sometimes runs free-voucher promotions for events such as Microsoft Build or Microsoft Ignite, so check your Microsoft Learn profile for any active offers before booking.

Is a passed DP-900 permanent, or does it lapse?

No. Microsoft Fundamentals certifications — including AZ-900, DP-900, AI-901, MS-900, and PL-900 — do not expire. Once you pass, the certification is yours for life. (This is different from Associate and Expert certifications such as DP-300 or AZ-104, which require an annual free renewal assessment on Microsoft Learn.)

Is relational vs non-relational the hardest DP-900 call?

For most candidates, yes. DP-900 repeatedly asks you to match a workload to the right storage model — a relational schema with joins and transactions vs a document, key-value, column-family, or graph store built for a different access pattern. Azure Mastery's Answer Coach flags exactly which property of the scenario (structure, consistency need, query shape) should have driven the choice, rather than leaving you to memorise service names in isolation.

I failed DP-900 once — what's the wait before I can resit?

The first retake is allowed after 24 hours. Second and third retakes each require a 14-day wait. Microsoft caps retakes at five attempts per 12-month rolling period. Each attempt requires a new voucher purchase.

Is DP-900 worth sitting if I'm not a developer or DBA?

Yes — Microsoft positions DP-900 for both technical and non-technical candidates. Data analysts about to step into Power BI work, software engineers crossing into a data role, and product managers responsible for analytics architecture all sit DP-900. The exam doesn't ask you to write SQL queries. It asks you to recognise scenarios — "which Azure SQL service for this workload?" or "which storage tier for this access pattern?" — and pick the correct option.
