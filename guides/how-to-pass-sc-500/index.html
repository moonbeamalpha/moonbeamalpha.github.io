How to pass SC-500: Cloud and AI Security Engineer

A practical six-week route through identity, storage, network, compute, and AI security — plus posture management — for Microsoft's newest security engineering exam, the exam that replaced AZ-500.

Updated 4 September 2026 · ~10 min read

The exam

What is SC-500, and is it for you?

SC-500 earns the Microsoft Certified: Cloud and AI Security Engineer Associate credential. It targets security engineers who protect organisational systems and data across cloud and hybrid environments, spanning identity, network, application, data, and compute — and who now also help secure the platforms, data, and infrastructure behind AI workloads.

SC-500 is the direct successor to AZ-500 (Microsoft Azure Security Engineer), which retired on 31 August 2026. Most of AZ-500's identity, storage, database, network, and compute security content carries over into SC-500 largely unchanged. What is genuinely new is a dedicated Secure compute for AI skill group — Purview Data Security Posture Management for Copilot, Microsoft Entra Agent ID, AI Gateway in API Management, Defender for AI Services, and Foundry guardrails — reflecting how much of a modern security engineer's estate now includes AI workloads rather than just infrastructure.

SC-500 became generally available on 1 July 2026, so it is still a young credential and the AI-security content in particular has little third-party prep material. Expect scenario-driven questions built around GA features with occasional coverage of commonly used preview capabilities. The skills measured were last confirmed on 13 May 2026, so anchor your study to that live outline rather than older AZ-500 material, which covers a different, retired exam.

Format & domains

Exam format and skills domains

SC-500 mixes question styles: single-answer and multi-select items, ordering tasks around a configuration or investigation workflow, and case studies that group several questions around one security-engineering scenario.

  • QuestionsRoughly 40–60
  • Duration100 minutes (120 min seat)
  • Pass score700 / 1000 (scaled)
  • DeliveryOnline or a test centre
  • ValidityRenew free every year
  • FeeVaries by country

The exam fee changes from country to country, so check Microsoft's certification page for the price where you live. The four skills domains and their weights, from the official May 2026 outline, are below.

Six-week study plan

A realistic six-week study plan

Candidates who already administer Azure security day to day tend to pass in five to eight weeks; if Microsoft Sentinel, Entra Agent ID, or the AI-security controls are unfamiliar, stretch this toward three months. Six weeks below gives the largest domain — storage, databases, and networking — two full weeks, with the remaining three domains taking one week each.

  1. Manage identity, access, and governance

    Secure access with Microsoft Entra ID: Privileged Identity Management, Conditional Access, multifactor and passwordless authentication, application identities and OAuth consent, and managed identities. Then Key Vault: deployment, access policies, firewall rules, and Defender for Key Vault. Close with governance: Azure Policy, Defender for Cloud compliance standards, resource locks, RBAC and custom roles, and infrastructure-as-code controls.

  2. Secure storage and databases

    Secure storage accounts: firewall rules, Defender for Storage threat protection, and access policies. Then secure databases: platform-level security in Azure SQL, database auditing, and Defender for Databases across Azure's database services.

  3. Secure Azure network services

    Network and application security groups, Azure Virtual Network Manager access policies, Virtual WAN security, VPN connections, Microsoft Entra Private Access, private endpoints and Private Link for platform-as-a-service resources, Azure Firewall, and effective security rules via Network Watcher.

  4. Secure compute: AI, servers, and the application platform

    Give the headline addition over AZ-500 a deliberate deep dive: Purview Data Security Posture Management for Copilot and AI apps, real-time protection for Copilot Studio agents, Conditional Access and blast-radius analysis for Microsoft Entra Agent ID, AI Gateway in API Management for Microsoft Foundry, Defender for AI Services, and Foundry agent guardrails. Then servers and VMs (disk encryption, Azure Bastion, just-in-time access, Azure Arc, Defender for Servers, secure boot and vTPM) and the application platform (Defender for Containers, AKS, Container Apps, Functions, Logic Apps, App Service, and the Web Application Firewall).

  5. Manage and monitor security posture

    Defender for Cloud's CSPM, compliance frameworks, workload protection plans, and multicloud AWS/GCP connectors. Then Microsoft Sentinel ingestion: workspaces, data connectors, syslog and CEF collection, Windows event collection, automation rules and playbooks. Finish with Microsoft Security Copilot: workspaces, permissions, plugins, and agents.

  6. Review and exam simulation

    Revisit the control-layering distinctions the exam leans on hardest: which Defender for Cloud plan covers which resource, and which network-access control fits which pattern. Then switch to sharpening: drill your weakest domain daily and sit two full-length timed practice runs. Book the exam once your readiness sits comfortably above the pass mark.

Where people lose marks

The hardest SC-500 topics

SC-500's breadth means most candidates know a little about every domain, but these five areas consistently expose gaps because the right control is easy to confuse with a similar-sounding one.

The AI-security control set

Purview DSPM, Entra Agent ID Conditional Access, AI Gateway, Defender for AI Services, and Foundry guardrails all touch AI workloads but stop different threats — data overexposure, agent identity misuse, model-endpoint abuse, and runtime prompt attacks respectively. Practise matching the named risk in a scenario to the one control that actually addresses it.

Private network access patterns

Private endpoints, Azure Private Link, Microsoft Entra Private Access, and Azure Virtual Network Manager all restrict access in different ways, and the exam expects you to pick the one that fits the access pattern — a PaaS resource, a user connecting from outside Azure, or centralised policy across many virtual networks — rather than the one you know best.

Which Defender for Cloud plan covers what

Defender CSPM, and the individual plans for Storage, Databases, Servers, Containers, and Key Vault, overlap in the dashboard but protect different resource types with different feature sets. Questions naming a specific resource and threat expect the specific plan, not a generic "enable Defender for Cloud" answer.

Governance layering: policy, RBAC, and locks

Azure Policy, RBAC role assignments, resource locks, and Key Vault access policies each stop a different kind of misconfiguration, and SC-500 tests which layer actually prevents the scenario described — an accidental deletion, an overprivileged assignment, or a non-compliant resource being created in the first place.

Matching a Sentinel ingestion method to the source

Built-in data connectors, syslog/CEF forwarding, data-collection-rule-based Windows Event collection, and custom log tables all get data into Microsoft Sentinel, but each suits a different source type and licensing model. Learn to read a source description and name the correct ingestion path rather than defaulting to whichever method is most familiar.

How to practise

Practise the way the exam works

Reading Defender for Cloud documentation builds familiarity with feature names, but SC-500 tests which specific control or plan fits a described threat, which is a different skill. Retrieval practice closes that gap: read a scenario, name the control before you check the answer, and pay particular attention to the AI-security material, since it is the newest and least reinforced by prior experience for most candidates coming from an AZ-500 background.

Pair that with spaced repetition across all four domains, since identity, storage and networking, compute, and posture management can each fade independently if you study them once and move on — SC-500's breadth is exactly what makes this matter more than on a narrower exam. Then close with full-length simulation: a timed, mixed-domain run is the only way to check whether you can keep matching controls to threats correctly once fatigue sets in during the back half of the paper. Sit at least two before you book, and review every wrong answer rather than just the score.

Exam day

Tactics for exam day

If you are sitting online, run the system check the day before and clear your desk, since proctors will ask you to show the room and remove anything within reach. Arrive early either way, because a rushed start eats into your focus during the dense scenario questions.

With 100 minutes for 40 to 60 questions you have roughly a minute and a half to two minutes each, which is comfortable if you keep moving. Use the mark-for-review flag on anything that makes you pause and return to it once you have banked the easy marks. Read every network- or Defender-for-Cloud question twice: the trap is usually a single scope, resource type, or plan name, and a slower second read pays off more than on a straightforward recall question.

Case studies bundle several questions around one security-engineering scenario, and once you move past a case you generally cannot return to it, so answer everything inside a case fully before advancing. Remember the score is scaled: you need 700 out of 1000, not a perfect run, so an unfamiliar configuration is not a disaster. Flag it, make your best call, and keep your momentum.

Frequently asked

SC-500 FAQs

How hard is the SC-500 exam?

SC-500 is broad rather than deep: it spans identity, storage, database, network, compute, and AI security, plus posture management, so the challenge is breadth of recall as much as difficulty of any one topic. The AI-security material — Entra Agent ID, Purview DSPM, Defender for AI Services, Foundry guardrails — is newest and least documented, so it tends to cost the most marks. Candidates with hands-on Defender for Cloud and Microsoft Entra ID experience typically pass after five to eight weeks.

How long should I study for SC-500?

Plan for five to eight weeks if you already administer Azure security day to day. If Microsoft Sentinel, Microsoft Entra Agent ID, or the newer AI-security controls are unfamiliar, two to three months is more realistic, since several of these capabilities are recent additions with less established documentation. The six-week plan on this page is a sensible middle path for most candidates coming from a security-engineering background.

Do I need AZ-500 or SC-200 before SC-500?

Neither is a formal prerequisite. Microsoft expects practical experience administering Azure and hybrid environments, strong familiarity with Microsoft Entra ID, and some Microsoft 365 administration exposure — the kind of background AZ-500 or day-to-day cloud security work already gives you. If you were partway through AZ-500 preparation, that study carries over directly, since SC-500 keeps the core Azure security-engineering content and adds the AI-security domain.

Is SC-500 the same as AZ-500?

SC-500 is the direct successor to AZ-500, which retired on 31 August 2026. Most of AZ-500's identity, storage, database, network, and compute security content carries over unchanged. The difference is the new Secure compute for AI skill group — Microsoft Purview DSPM, Microsoft Entra Agent ID, AI Gateway, Defender for AI Services, and Foundry guardrails — which did not exist on AZ-500 and now accounts for a meaningful share of the paper.

What is the passing score for SC-500, and does it expire?

You need 700 out of 1000 to pass, on a scaled score rather than a raw percentage, so it does not map to a fixed number of correct answers. Like other Microsoft Associate certifications, SC-500 also expires annually, with a free online renewal assessment on Microsoft Learn that opens in the six-month window before your expiration date.

How much does SC-500 cost and can I retake it if I fail?

Exam pricing varies by country, so check Microsoft's certification page for the fee where you live rather than trusting a figure you read elsewhere. If you do not pass, the first retake is allowed after 24 hours, the second and third each require a 14-day wait, and Microsoft caps retakes at five attempts per rolling 12-month period. Each attempt needs a new booking.
