The exam

What is the AB-650 exam?

AB-650 is the Microsoft 365 Certified: AI Services Administrator Associate credential — currently a beta exam — the role-based exam for administrators who configure, manage, secure, and govern Microsoft 365 tenants, workloads, and AI services. That covers Microsoft 365 Copilot, whatever agents your organisation deploys, and the newer Microsoft Agent 365 governance surface. AB-650 spans configuring the tenant itself, governing and securing identities, workloads and data, and managing and securing the AI services layer end to end.

AB-650 is tenant-admin and governance-aware — it is not a builder exam. It validates that you can configure and manage a Microsoft 365 tenant and its workloads (branding, domains, licensing, Microsoft 365 Backup, mailboxes, Teams, SharePoint for Copilot), govern and secure the tenant (Microsoft Entra identities, authentication and Conditional Access, Microsoft Defender for Office 365, Microsoft Purview data protection), and manage and secure AI services (Copilot readiness and settings, Microsoft Entra Agent ID, the agent registry, Agent 365 governance, and Copilot Control System monitoring). Expect scenario questions that hand you a tenant configuration or a stated requirement and ask which specific control satisfies it.

Because AB-650 is in beta, Microsoft is still gathering data on question quality before scoring is finalised. Every question in Azure Mastery's AB-650 bank is mapped to the skills measured on the current outline. Read the official Microsoft study guide.

Official Microsoft skills outline

AB-650 exam objectives

Three domains from Microsoft's current outline. Every domain summary below is paraphrased from the official study guide; Azure Mastery tags each question so you can see where your weak spots cluster.

Configure and manage Microsoft 365 tenants and workloads20–25%

Explore key topics

The baseline layer. Configure the tenant itself — branding, domains, organisational settings, group-based and pay-as-you-go licensing including licences for Microsoft 365 Copilot, Microsoft Agent 365, and Microsoft Copilot Studio — plus Microsoft 365 Backup setup, restore and monitoring, network connectivity insights, and service health. Then manage the workloads themselves: mailboxes, Microsoft Teams (channels, owners, members, and the Copilot meeting-transcription policy), and SharePoint sites configured for Copilot (SharePoint Advanced Management, Microsoft Search in SharePoint, site exclusions).

Govern and secure Microsoft 365 tenants and workloads40–45%

Explore key topics

Largest domain by far. Manage identities in Microsoft Entra — users, guest and external access, groups, role assignments and Privileged Identity Management, administrative units, and bulk management through Microsoft Graph PowerShell. Implement authentication and access — methods, Password Protection, self-service password reset, and Conditional Access with ID Protection and multifactor authentication. Secure workloads with Microsoft Defender for Office 365 — alerts, threat policies, investigation, and attack simulation training. Protect data with Microsoft Purview — data loss prevention across Exchange, SharePoint, OneDrive, Teams, endpoints and Copilot; sensitivity labels; retention; and Data Security Posture Management for AI activity.

Manage and secure AI services in Microsoft 36535–40%

Explore key topics

The newest, fastest-moving domain. Enable and manage Microsoft 365 Copilot — tenant readiness, data-readiness and oversharing remediation, Copilot Search, tenant settings including the AI disclaimer, Microsoft 365 Copilot Cowork, third-party providers, and connectors. Implement and manage agents in Microsoft 365 and Agent 365 — lifecycle workflows through Microsoft Entra Agent ID, agent owners, allowed types and templates, and the agent registry for discovering, reviewing, publishing, blocking, and installing agents. Secure and govern agents with Agent 365 — activity monitoring, sensitive-data protection, and compliance-gap evaluation. Monitor AI services — cost, Copilot adoption reporting, and service health through the Copilot Control System.

6-week study plan

Suggested AB-650 study plan

Most candidates prepare for AB-650 in four to eight weeks, depending on their Microsoft 365 and Microsoft Entra administration experience. The six-week plan below weights the two largest domains — govern/secure and AI services — with two weeks each, Azure Mastery's adaptive sessions, and the in-app exam simulator. Adjust the pace to your background — the readiness gauge tells you when you're done, not the calendar.

  1. Tenant and workloads

    • Week 1: Configure and manage a Microsoft 365 tenant — branding, domains, organisational settings, licensing including AI-service licences, Microsoft 365 Backup, network connectivity insights, service health. Then manage workloads — mailboxes, Teams, SharePoint sites, and the Copilot meeting-transcription policy matrix.

  2. Govern and secure (largest domain, 40–45%)

    • Week 2: Identities in Microsoft Entra — users, guests, groups, roles and Privileged Identity Management, administrative units, bulk management via Microsoft Graph PowerShell. Then authentication and access — methods, Password Protection, self-service password reset, Conditional Access and ID Protection.
    • Week 3: Secure Microsoft 365 workloads with Defender for Office 365 — alerts, threat policies, investigation, attack simulations. Then protect data with Microsoft Purview — DLP across workloads and Copilot, sensitivity labels, retention, and Data Security Posture Management.

  3. Manage and secure AI services (35–40%)

    • Week 4: Enable and manage Microsoft 365 Copilot — tenant readiness, data-readiness and oversharing remediation, Copilot settings, Copilot Search, Cowork, third-party providers, connectors.
    • Week 5: Implement and secure agents — Microsoft Entra Agent ID lifecycle, the agent registry, Agent 365 governance, and monitoring AI service cost, adoption and health through the Copilot Control System.

  4. Sharpen and simulate

    • Week 6: Run Focus Weak Spots every morning, drilling the highest-value distinctions the exam repeats. Then run two full-length Exam Simulator sessions at the full 120-minute length. Schedule the exam when readiness gauge is 750+ with reasonable confidence.

Frequently asked

AB-650 FAQs

How much does the AB-650 exam cost?

Microsoft prices AB-650 by the country or region where the exam is proctored and has not published a single flat fee for the beta — check the official exam page for your local price when you register. During a beta, Microsoft sometimes opens a short discounted-registration window (announced on the Microsoft Learn blog) with a discount code for a limited number of seats. The certification renews annually with a free online assessment once you're certified, so there is no recurring fee.

Does the AB-650 certification expire?

Yes. Microsoft Associate certifications including AB-650 expire annually. Renewal is free — a short online assessment on Microsoft Learn within the six-month window before your expiration date. The renewal targets recent skills-outline updates, so staying current is straightforward if you remain broadly active in the role. (Fundamentals certifications such as AB-900 are different — those don't expire.)

What is the AB-650 retake policy if I fail?

AB-650's beta status changes this for now. If you don't pass a beta exam, Microsoft has you wait until the exam goes live before you can retake it — the usual 24-hour and 14-day retake windows don't apply during the beta window. Once AB-650 is fully live, Microsoft's standard retake policy takes over: a 24-hour wait before your first retake, 14-day waits before the second and third, and a cap of five attempts per rolling 12 months. Each attempt requires a new voucher.

How long should I study for AB-650?

Allow four to eight weeks of focused study if you already administer Microsoft 365 tenants and Microsoft Entra ID day to day. Spend longer if Microsoft Purview data protection, Conditional Access, Agent 365, or Microsoft Entra Agent ID are new to you. Azure Mastery's readiness gauge helps you decide when to schedule the exam.

AB-650 vs AB-620 — administer or build?

Different roles over the same agent estate. AB-620 is the AI Agent Builder Associate credential — the maker-role exam for designing, integrating, and testing agents inside Microsoft Copilot Studio. AB-650 is the administrator-role exam: it's about governing whatever agents your organisation ends up with, wherever they were built, across the wider Microsoft 365 tenant — licensing, identity, Defender and Purview protection, the agent registry, and Agent 365 monitoring. A Copilot Studio maker and a Microsoft 365 administrator often sit on the same team; AB-620 and AB-650 map to those two different jobs.

AB-650 vs AB-900 — do I need the fundamentals exam first?

AB-900 (Microsoft 365 Copilot and Agent Administration Fundamentals) is the conceptual on-ramp — it stays at the "what is it and why does it matter" level across core Microsoft 365 objects, data protection concepts, and basic Copilot and agent administration. AB-650 is the associate-level exam built on top of that: it expects you to actually configure the tenant settings, identity policies, and agent governance controls, and to defend the trade-offs between similar-looking options. AB-900 isn't a formal prerequisite for AB-650, but it's a solid foundation if Microsoft 365 administration is new to you.

AB-650 vs SC-300 — how much identity overlap is there?

Some overlap, different depth. SC-300 (Identity and Access Administrator) goes far deeper into Microsoft Entra identity architecture — hybrid identity, external identities, application integration, and identity governance at a specialist level. AB-650 covers the identity surface a Microsoft 365 administrator actually touches day to day — users, groups, administrative units, Conditional Access, and Privileged Identity Management — plus the newer agent identity model built on Microsoft Entra Agent ID, which SC-300 does not cover. Candidates who own both Microsoft 365 and deep identity architecture often hold both certifications.
