The exam

What is the AZ-104 exam?

AZ-104 is the Microsoft Certified: Azure Administrator Associate exam — the credential most hiring managers expect when posting "Cloud Administrator (Azure)" or "Azure Sysadmin" roles. It's the natural next step after AZ-900 for anyone who administers Azure environments day-to-day, and the foundation underneath architecture (AZ-305), cloud and AI security (SC-500), and networking (AZ-700) specialisms.

Unlike Fundamentals exams, AZ-104 is hands-on and practical. It validates that you can manage identities and RBAC at scale, implement storage with the right redundancy and access strategy, deploy and configure VMs, containers, and App Service, manage virtual networks and security groups, and monitor a live environment with Backup and Site Recovery in place for disaster recovery. Expect questions that show you a Bicep file or Azure CLI command and ask you to predict the outcome — not just describe a concept.

Microsoft updated the AZ-104 skills outline on 17 April 2026, with minor updates to storage configuration, virtual machine management, container provisioning, and monitoring. Every question in Azure Mastery's AZ-104 bank is mapped to the current outline — no leftover questions on retired features. Read the official outline at learn.microsoft.com.

The largest domain by typical question count, and the one everything else depends on. Entra ID objectives cover day-to-day user and group administration — creating accounts, managing licences, handling external users, and configuring self-service password reset — while access management is specifically about built-in role assignment at the right scope, and interpreting who actually has access once inheritance from management group down to resource is accounted for. Governance rounds it out: Azure Policy, resource locks, tagging discipline, resource-group and subscription hygiene, cost alerts and budgets, and management-group structure. Scope confusion — assigning a role at subscription level when a resource group would do — is the domain's classic trap.

Implement and manage storagePublished weight 15–20%

Explore Storage topics
  • Configure access to storage
  • Configure and manage storage accounts
  • Configure Azure Files and Azure Blob Storage

Storage questions are less about creating an account and more about configuring one correctly for a stated requirement. Access control spans firewall and virtual-network rules, SAS tokens and stored access policies, access keys, and identity-based access for Azure Files — four different mechanisms the exam expects you to distinguish. Account configuration covers redundancy tiers, object replication, and encryption; Azure Files and Blob Storage add file-share and container-level detail — soft delete, snapshots, lifecycle management, and versioning. Choosing the right redundancy or access tier for a described cost and durability requirement is tested more than raw factual recall.

The domain with the widest service surface. Infrastructure as code comes first — reading, modifying, deploying, and converting between ARM templates and Bicep files, not just writing one from scratch. Virtual machine objectives cover sizing, disks, encryption at host, availability zones versus availability sets, and Virtual Machine Scale Sets. Containers stay portal-focused: Container Registry, Container Instances, and Container Apps, with an emphasis on sizing and scaling rather than orchestration depth. Networking splits into three practical skill areas rather than pure theory. Core VNet configuration covers subnets, peering, public IP addressing, user-defined routes, and — critically — troubleshooting connectivity when a described setup isn't working as expected. Secure access covers NSGs and application security groups, evaluating effective security rules (not just the rules you wrote), Azure Bastion, and service and private endpoints for PaaS resources. Name resolution and load balancing rounds it out with Azure DNS and internal versus public load balancer configuration, including troubleshooting load-balancing behaviour.

The smallest domain by weight, but not to skip — it's frequently the deciding factor in borderline scores. Monitoring covers reading Azure Monitor metrics, configuring log settings, writing log queries, setting up alert rules and action groups, and using Insights for VMs, storage, and networks alongside Network Watcher's Connection Monitor. Backup and recovery covers Recovery Services and Backup vaults, writing backup policies, running backup and restore operations, and configuring Azure Site Recovery for cross-region failover — including interpreting the reports and alerts a backup job actually produces.

Common traps

Where AZ-104 candidates slip

Five recurring misconceptions that trip up otherwise well-prepared AZ-104 candidates, grounded in the current skills outline.

Subscription scope vs resource-group scope

AZ-104 scenarios frequently describe a role assigned at one scope and ask what a user can or can't do at another. A Contributor role assigned at the subscription level cascades down to every resource group inside it; one assigned at a single resource group never reaches sibling resource groups or the subscription itself. Reading exactly which scope a role was assigned at — not just which role — decides the answer.

Soft delete, versioning, and lifecycle management aren't the same control

Soft delete recovers a blob or container that was deleted; versioning keeps every prior version of a blob as you overwrite it; lifecycle management automatically moves or deletes blobs based on age or last-access rules you define. They solve three different problems and can run simultaneously, but a scenario asking specifically how to recover an overwritten blob wants versioning, not soft delete.

NSGs and application security groups aren't two names for the same thing

A network security group filters traffic to and from a subnet or NIC using explicit rules; an application security group is a way of grouping VMs by role — web tier, database tier — so an NSG rule can reference the group instead of individual IP addresses. An ASG on its own blocks nothing; it only becomes a security boundary once referenced inside an NSG rule.

Availability sets, availability zones, and scale sets protect against different failures

Availability sets protect against failure within a single datacenter by spreading VMs across fault and update domains; availability zones protect against failure of an entire datacenter by spreading VMs across physically separate facilities in a region; Virtual Machine Scale Sets add automatic scaling on top of either. A scenario asking for protection against a full datacenter outage needs zones, not sets — mixing these up is one of the exam's most common misses.

Service endpoints still leave a public IP; private endpoints don't

A service endpoint keeps traffic to a PaaS resource on the Azure backbone, but the resource still has a public IP reachable from outside the VNet unless firewalled; a private endpoint gives the PaaS resource a private IP address inside your VNet, removing public exposure entirely. Scenarios requiring that a resource have no public endpoint at all need a private endpoint specifically, not a service endpoint.

6-week study plan

Suggested AZ-104 study plan

Build from identity and storage to compute, networking and recovery. Follow these six weeks of study blocks, then use timed practice to decide what needs more attention.

  1. Microsoft Entra ID

    • Manage users, groups and licences.
    • Review external-user access.
    • Configure self-service password reset.

  2. Azure role-based access

    • Compare built-in roles.
    • Assign roles at management group and subscription scope.
    • Practise resource group and resource-level assignments.

  3. Governance and cost

    • Organise subscriptions and management groups.
    • Apply Azure Policy, locks and tags.
    • Set budgets and cost alerts.

  4. Storage accounts

    • Configure accounts and compare access methods.
    • Review redundancy and replication.
    • Apply encryption and identity-based Azure Files access.

  5. Files and blobs

    • Manage file shares, snapshots and soft delete.
    • Compare Blob Storage access tiers.
    • Configure lifecycle policies and versioning.

  6. Infrastructure as code

    • Read ARM templates and Bicep.
    • Practise modifying, deploying and converting templates.
    • Use Bicep question drills to check your understanding.

  7. Virtual machines

    • Practise provisioning, sizing and disk choices.
    • Compare availability zones, sets and scale sets.
    • Review encryption at host.

  8. Containers and web apps

    • Compare ACR, ACI and Container Apps.
    • Configure App Service plans and scaling.
    • Review certificates, custom DNS and deployment slots.

  9. Virtual networking

    • Configure VNets, subnets and peering.
    • Compare NSGs, application security groups and Bastion.
    • Review endpoints, Azure DNS and load balancers.

  10. Monitoring

    • Explore metrics, logs and log queries.
    • Configure alerts and action groups.
    • Review Insights and Network Watcher.

  11. Backup and recovery

    • Configure Recovery Services vaults and Azure Backup.
    • Review backup policies.
    • Practise Site Recovery failover testing.

  12. Target weaker topics

    • Run Focus Weak Spots sessions.
    • Review explanations for missed questions.
    • Return to domains that need more practice.

  13. Timed rehearsal

    • Complete two 100-minute Exam Simulator sessions.
    • Review each run carefully.
    • Identify recurring mistakes.

  14. Light review

    • Revisit your key notes.
    • Allow time to rest.
    • Use your practice results to decide whether more study is needed.

Frequently asked

AZ-104 FAQs

How much does the AZ-104 exam cost?

The AZ-104 voucher is USD $165 in the United States. Pricing varies by region — in the UK it's typically around £128. Microsoft sometimes runs free-voucher promotions during events such as Microsoft Build or Microsoft Ignite, so check your Microsoft Learn profile for any active offers before booking. AZ-104 also requires annual renewal (free, online), so factor that into long-term cost planning.

Does the AZ-104 certification expire?

Yes. Microsoft Associate certifications including AZ-104 expire annually. Renewal is free — a 25–30 question online assessment on Microsoft Learn within the six-month window before your expiration date. The renewal targets recent skills outline updates, so staying current is straightforward if you remain broadly active in the role. (Fundamentals certifications such as AZ-900 are different — those don't expire.)

What is the AZ-104 retake policy if I fail?

The first retake is allowed after 24 hours. Second and third retakes each require a 14-day wait. Microsoft caps retakes at five attempts per 12-month rolling period. Each attempt requires a new voucher purchase.

How long should I study for AZ-104?

Most candidates plan four to eight weeks with prior Azure experience, or longer if they are new to administration. Practise identity and governance, storage, compute, virtual networking, and monitoring in the portal and with Azure CLI, PowerShell, and Bicep so you can choose and apply the right administration method. Azure Mastery's readiness gauge tells you when you're exam-ready.

What prior experience does AZ-104 assume?

AZ-104 assumes familiarity with operating systems, networking, servers, and virtualisation, plus hands-on experience with PowerShell, Azure CLI, the Azure portal, and ARM templates or Bicep files. It isn't written for someone with zero IT background — Microsoft expects a working administrator, not a beginner learning what a virtual machine is. If those fundamentals are genuinely new, AZ-900 first (or general IT experience) will make AZ-104 far more approachable.

AZ-104 vs AZ-900 — which should I take first?

If you have less than six months of hands-on Azure experience, take AZ-900 (Microsoft Azure Fundamentals) first — it builds the conceptual map AZ-104 assumes you already have. If you have a year or more of practical Azure work, you can skip AZ-900 and go straight to AZ-104. Most hiring managers care about AZ-104 specifically; AZ-900 is often dropped from CVs once AZ-104 is on it.

AZ-104 vs AZ-305 — which next?

Pass AZ-104 first. AZ-104 is the Associate-level operational cert; AZ-305 is the Expert-level architectural cert. AZ-305 assumes you already understand Azure operations (the AZ-104 material) and adds requirements gathering, capacity planning, governance design, and choosing between competing service options. Most architects hold both — AZ-104 to prove they've done the work, AZ-305 to prove they can design it.
