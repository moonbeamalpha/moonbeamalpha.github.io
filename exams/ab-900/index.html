The exam

What is the AB-900 exam?

AB-900 is the Microsoft 365 Copilot and Agent Administration Fundamentals credential — the entry-level exam for IT admins who deploy, govern, and support Microsoft 365 Copilot and Copilot agents in an enterprise.

AB-900 is practical and admin-centre-focused. It covers:

  • Core Microsoft 365 features and objects across admin centres, identity, and security
  • Data protection and governance through Microsoft Purview — Information Protection, DLP, Insider Risk, DSPM for AI, and Data Lifecycle Management
  • How Copilot accesses data via Microsoft Graph while respecting M365, Purview, and Defender controls
  • Basic admin tasks: assigning Copilot licences, monitoring PAYG billing, approving agents, and tracking agent usage across the M365 and Power Platform admin centres

Expect questions that ask which admin centre or which Purview tool fits a stated business need.

Microsoft published the AB-900 skills outline on 22 July 2026. Every question in Azure Mastery's AB-900 bank is mapped to the current outline — including the newer DSPM for AI, Copilot Analytics, and SharePoint oversharing topics. Read the official outline at learn.microsoft.com.

Common traps

Where AB-900 candidates slip

Five recurring misconceptions that trip up otherwise well-prepared AB-900 candidates, grounded in the current skills outline.

Know the primary admin surface for each Microsoft 365 workload

Candidates treat the admin centres as interchangeable consoles rather than each owning a distinct set of objects.

  • Object-to-centre mapping is the graded skill, ahead of simply recognising each console by name.
  • Match the object named in the scenario to the primary admin surface for that workload, while remembering that some settings are visible in more than one portal.

A Copilot licence and pay-as-you-go billing solve different usage patterns

Both are ways to pay for Copilot, so candidates assume the exam only cares that a valid billing method was picked.

  • Usage pattern is the variable under test, since both options technically switch Copilot on for the user.
  • Check whether the scenario describes steady or occasional usage before choosing between a licence and pay-as-you-go billing.

DSPM for AI is scoped to AI tools, not general data loss

Standard DLP and DSPM for AI both stop sensitive content leaking, so candidates default to the more familiar DLP answer.

  • AB-900 checks whether you route a prompt-or-grounding-data leak to DSPM for AI instead of standard DLP.
  • Pick DSPM for AI whenever the scenario describes a risk coming specifically from a Copilot or agent response.

Sensitivity labels protect content; oversharing reports find it after the fact

Both sit inside Microsoft Purview, so candidates reach for labelling whenever a question mentions who can access a file.

  • Telling protection from detection apart is the graded skill, since only one tool shows who has access right now.
  • Pick an oversharing report, not a sensitivity label, for any question about auditing who currently has access to a site.

Administering an agent is not the same task as building one

AB-900 tests who can use, publish, or monitor an agent, never how the agent's own conversation logic works.

  • The admin's job, approving and monitoring an agent, is what's graded here, never the maker's conversation design.
  • Rule out any answer describing conversation design; that work belongs to a separate Copilot Studio certification, not this exam.

Frequently asked

AB-900 FAQs

Which admin centre owns a given object — is that a recurring AB-900 trap?

Yes. AB-900 often gives an object, a mailbox setting, a Teams policy, a SharePoint site, and expects you to know which admin centre actually owns it, rather than treating the centres as interchangeable. Answer Coach names the specific centre a wrong pick would have sent you to instead.

AB-900 vs SC-900 — which should I take first?

Different scopes. SC-900 is the broad Microsoft security overview: Entra, Defender, Purview, identity. AB-900 is narrower and practical, focused on M365 Copilot administration, with Purview coverage scoped to the Copilot threat surface. Passed SC-900 already? AB-900 feels like an extension. New to both? Start with AB-900 if your role is Copilot-focused.

What question formats should I expect on AB-900?

Most Microsoft Fundamentals exams contain 35–50 questions, but the exact count and formats vary by sitting. Azure Mastery's original practice bank includes single-select, scenario, yes/no, multi-select, drag-to-match, hot-area, drag-and-drop, dropdown, and case-study interactions.

What's the AB-900 exam fee, and does it vary by region?

The listed US price is USD $99, while regional pricing and promotions can change. Check Microsoft's exam page and current offers before booking. Fundamentals certifications never expire, so there's no annual renewal cost.

Once earned, does an AB-900 credential ever lapse?

No. AB-900, like other Microsoft Fundamentals certifications (AZ-900, AI-901, SC-900, DP-900), never expires once earned. Associate and Specialty certifications differ: those require annual renewal on Microsoft Learn.

DSPM for AI vs standard DLP — how does AB-900 tell them apart?

AB-900 tests whether you know DSPM for AI is scoped to Copilot and agent interactions, flagging oversharing and exposure risk in prompts and grounding data, while standard DLP governs data movement across email, Teams, and file storage generally. Picking the wrong one is the exact mix-up Answer Coach catches.

I failed AB-900 — how soon can I book a retake?

The wait before your first retake is 24 hours.

  • First retake: 24-hour wait.
  • Second and third retakes: 14-day wait each.
  • Microsoft caps you at five attempts within any rolling 12-month period, a voucher required each time.
AB-900 vs AB-620 — what's the difference?

Different jobs. AB-900 is the Fundamentals-tier admin cert: identifying M365 admin-centre objects, Purview surfaces, and Copilot administration controls. AB-620 (AI Agent Builder) is the Associate-tier maker cert: building agents in Copilot Studio with topics and knowledge sources. AB-900 administers; AB-620 builds. Many admins take both.
