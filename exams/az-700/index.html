The exam

What is the AZ-700 exam?

AZ-700 is the Microsoft Certified: Azure Network Engineer Associate exam — the credential hiring managers expect for "Cloud Network Engineer" or "Azure Networking Specialist" roles. It's the natural next step after AZ-104 once your day job shifts from generalist administration into network-specific design. AZ-700 also pairs with SC-500 for cloud-network security and feeds the AZ-305 architect track for networking specialists.

AZ-700 is hands-on and design-oriented. It validates that you can plan and implement across five areas:

  • Network infrastructure — VNets, subnets, IP plans, route tables
  • Hybrid connectivity — VPN Gateway, ExpressRoute, Virtual WAN
  • Application delivery — Azure Load Balancer, Application Gateway, Front Door, Traffic Manager
  • Private access to PaaS — Private Link, Private Endpoints, service endpoints
  • Network security — Azure Firewall, Firewall Manager, NSGs, DDoS Protection, WAF

Expect scenario questions where a customer has a constraint — "spoke VNets must reach an on-prem subnet without traversing the hub" — and you pick the right service combination.

Common traps

Where AZ-700 candidates slip

Three recurring misconceptions that trip up otherwise well-prepared AZ-700 candidates, grounded in the current skills outline.

A service endpoint and a private endpoint restrict different things

A service endpoint keeps a resource's public IP, while a private endpoint gives it a private IP and removes public exposure entirely.

  • The exam is testing whether you'd choose Private Link over a service endpoint when no public exposure is allowed.
  • Reach for a private endpoint whenever the scenario explicitly rules out any public IP.

Application Gateway and Front Door aren't interchangeable just because both do Layer 7

Application Gateway is regional, while Azure Front Door is global with edge points of presence and built-in caching.

  • Picking a global service for cross-region routing instead of a regional one is exactly what's being tested.
  • Match global or regional in the stem to Front Door or Application Gateway before answering.

Virtual WAN and hub-and-spoke solve the same problem at different scale

Hub-and-spoke via VNet peering suits a handful of spokes, while Virtual WAN automates routing for large branch counts.

  • Matching the number of branch sites in a scenario to the right topology is the real test here.
  • Count the spokes or branches described before choosing between Virtual WAN and plain peering.

6-week study plan

Suggested AZ-700 study plan

Build networking foundations, then practise traffic delivery, private access and protection. Use the final study blocks of this six-week route for review and timed rehearsal.

  1. Virtual network design

    • Plan subnets and IP addressing.
    • Compare regional and global peering.
    • Review gateway transit and hub-and-spoke designs.

  2. Routing and topology

    • Configure route tables and user-defined routes.
    • Review BGP routes and propagation.
    • Compare hub-and-spoke with Virtual WAN.

  3. Azure DNS

    • Compare public and private zones.
    • Configure virtual network links.
    • Review registration, resolution and conditional forwarding.

  4. Hybrid connectivity

    • Compare site-to-site, point-to-site and VNet-to-VNet VPNs.
    • Review ExpressRoute circuits, peerings, FastPath and Direct.
    • Explore Virtual WAN hubs and branch connections.

  5. Azure Load Balancer

    • Compare public and internal load balancing.
    • Configure backend pools and health probes.
    • Review NAT rules.

  6. Application delivery

    • Configure Application Gateway routing, TLS and autoscaling.
    • Review WAF integration.
    • Explore Front Door caching, domains and global delivery.

  7. Traffic Manager

    • Compare priority, weighted and performance routing.
    • Review geographic, multi-value and subnet routing.
    • Choose between Traffic Manager and Front Door.

  8. Private connectivity

    • Distinguish Private Link, private endpoints and service endpoints.
    • Review VNet integration for App Service and Functions.
    • Explore Private Link Service across tenants.

  9. Firewall and network rules

    • Review Azure Firewall rules, threat intelligence and Firewall Manager.
    • Explore Premium IDPS and TLS inspection.
    • Analyse NSG and ASG rules and flow logs.

  10. Web and DDoS protection

    • Compare managed and custom WAF rules.
    • Review geographic filtering and rate limits.
    • Compare DDoS plans and mitigation reports.

  11. Target weaker topics

    • Use Focus Weak Spots to identify gaps.
    • Revisit core infrastructure and connectivity decisions.
    • Review the explanations for missed questions.

  12. Timed rehearsal

    • Complete two 100-minute Exam Simulator sessions.
    • Review mistakes after each run.
    • Plan further practice where needed.

Frequently asked

AZ-700 FAQs

What does the AZ-700 exam format actually look like?

AZ-700 follows Microsoft's general 40–60 question guidance, with formats varying by sitting. Azure Mastery's bank weights single-answer and scenario-based items heaviest, then adds multi-select, hotspot, and linked case-study questions — every one original, never a copy of Microsoft's live item mix.

AZ-700 vs AZ-104 — should I do AZ-104 first?

Microsoft strongly recommends it, and it shows. AZ-700 assumes you already know how Azure compute, storage, and the basic VNet model work day-to-day. If you've never deployed a VM with a public IP or set up a basic NSG, take AZ-104 first. Working network engineers can often skip straight in.

What's the current AZ-700 voucher price?

The AZ-700 voucher is USD $165 in the US, or around £128 in the UK — pricing varies by region. Microsoft sometimes runs free-voucher promotions around Build or Ignite. AZ-700 also needs annual renewal, so factor that into long-term cost planning.

Does AZ-700 overlap with cloud security certs like SC-500?

A little, but the roles differ. AZ-700 treats network security (Firewall, NSGs, WAF) as one domain among five. SC-500 applies security controls across an entire cloud and AI estate, well beyond networking. Take AZ-700 for network engineering depth; add SC-500 for end-to-end cloud security.

Does the AZ-700 badge need renewing every year?

Yes. Associate certifications including AZ-700 expire annually. Renewal is a free 25–30 question assessment on Microsoft Learn within six months of your expiry date. Fundamentals certs like AZ-900 are different — those never expire.

Do I need a home lab to pass AZ-700?

Hands-on time helps more here than on most Associate exams, since AZ-700 is a design-and-build exam, not pure recall. A free-tier subscription is enough to build a hub-and-spoke topology, a site-to-site VPN, and an Application Gateway deployment. Azure Mastery's scenarios cover the harder-to-lab decisions too.

If I don't pass AZ-700, when can I try again?

Not immediately, and each attempt needs its own voucher.

  • First retake: after 24 hours.
  • Second and third retakes: a 14-day wait each.
  • Cap: five attempts per rolling 12 months.
How many weeks of AZ-700 prep is realistic?

Most candidates plan four to eight weeks with prior Azure networking experience. Build and troubleshoot virtual networks, hybrid connectivity, routing, private access, application delivery, and network security in a lab. Azure Mastery's readiness gauge tells you when you're exam-ready.
