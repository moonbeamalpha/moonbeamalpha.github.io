        Frequently asked

        Questions, answered

        Is Azure Mastery free?

        Azure Mastery is free to download and includes a starter set of practice questions for every supported exam. Full per-exam question banks are available as one-time in-app purchases. There is no subscription required to use core study features, and no account is required.

        Which Microsoft certifications does Azure Mastery cover?

        Azure Mastery covers 35 Microsoft certification exams: AZ-900, AZ-104, AZ-204, AZ-305, AZ-400, AZ-500, AZ-700, AI-900, AI-901, AI-102, AI-103, AI-200, AI-300, AI-500, AB-100, AB-410, AB-620, AB-650, AB-731, AB-900, DP-900, DP-100, DP-300, DP-700, DP-750, DP-800, SC-900, SC-100, SC-200, SC-300, SC-500, PL-300, PL-900, GH-900, and GH-300. The app spans Azure infrastructure, AI engineering, data, security and compliance, Microsoft 365 Copilot administration, AI transformation leadership, SQL AI development, agentic AI architecture, multi-agent AI engineering, and Power BI roles.

        How does the Exam IQ score work?

        Exam IQ is an on-device CoreML model that predicts your likely exam-day score with confidence intervals. It uses Item Response Theory to score each answer by question difficulty, discrimination, and guessing, then updates your ability estimate per exam domain using Bayesian inference. Predictions are calibrated against Microsoft's published pass thresholds rather than raw percentage correct.

        Does Azure Mastery work offline?

        Yes. Core study — including the question bank, Exam IQ score prediction, adaptive study plans, and authored Answer Coach guidance — works without a connection. Optional model rewriting happens on-device, and optional sync uses the learner's private iCloud account. Azure Mastery has no study-data server or behavioural telemetry.

        Does Azure Mastery support iPad and Apple Watch?

        Yes. Azure Mastery is a native SwiftUI app for iPhone and iPad, with full Stage Manager and large-screen layouts on iPad. An Apple Watch companion shows your daily streak and XP at a glance. Live Activities surface the active study session timer on the lock screen and Dynamic Island.

        How is Azure Mastery different from other Microsoft exam prep apps?

        Azure Mastery is designed to tell you when you are ready to pass, not just to drill questions. It calibrates predicted scores against Microsoft's real pass thresholds, estimates ability per exam domain so you can see exactly which area is dragging your predicted score down, and uses spaced-repetition signals to flag topics where retention has decayed. All ML runs on-device with no telemetry.

        What kinds of practice questions are included?

        The app includes 14,300+ practice questions across 35 Microsoft exams. Question types match Microsoft's real exam formats: multiple choice, multi-select, drag-and-drop ordering, hotspot, and case studies. Each question includes a written rationale. When an answer is missed, Answer Coach uses authored certification guidance to explain the misconception, key distinction, and rule to remember; supported devices may optionally rewrite the note on-device after grounding checks.

        Who makes Azure Mastery?

        Azure Mastery is published by Moonbeam Alpha Ltd, an independent iOS app studio focused on certification preparation. The app is not affiliated with or endorsed by Microsoft.
