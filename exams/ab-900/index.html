The exam

What is the AB-900 exam?

AB-900 is the Microsoft 365 Copilot and Agent Administration Fundamentals credential — the entry-level exam for IT admins who deploy, govern, and support Microsoft 365 Copilot and Copilot agents in an enterprise. AB-900 covers the core features and objects of Microsoft 365 (admin centres, identity, security), data protection and governance via Microsoft Purview, and the basic administrative tasks for Copilot and agents (licensing, monitoring, agent approval, lifecycle).

AB-900 is practical and admin-centre-focused. It validates that you can identify the right Microsoft 365 admin centre and object for a task (Exchange, SharePoint, Teams, M365), recognise Microsoft Purview surfaces (Information Protection, DLP, Insider Risk, DSPM for AI, Data Lifecycle Management), understand how Copilot accesses data via Microsoft Graph and respects M365 / Purview / Defender controls, and perform basic admin tasks (assign Copilot licences, monitor PAYG billing, approve agents, monitor agent usage in M365 and Power Platform admin centres). Expect questions that ask which admin centre or which Purview tool fits a stated business need.

Microsoft published the AB-900 skills outline in May 2026. Every question in Azure Mastery's AB-900 bank is mapped to the current outline — including the newer DSPM for AI, Copilot Analytics, and SharePoint oversharing topics. Read the official outline at learn.microsoft.com.

Identify the core features and objects of Microsoft 365 services30–35%

Explore key topics

The M365 admin foundation. Identify the right admin centre and object for a task — M365 admin centre (domain names, org settings, licences), Exchange Online (mailboxes, distribution lists), SharePoint in M365 (sites, libraries, permissions), Teams (teams, channels, policies). Understand Microsoft 365 security principles — Zero Trust, authentication / authorisation methods, Microsoft Defender XDR features. Identify Microsoft Entra capabilities — conditional access, SSO, MFA, Privileged Identity Management (PIM), App registrations and Enterprise apps, audit logs, Identity Secure Score, and tools for common sign-in troubleshooting. Around 11–16 questions per sitting.

Understand data protection and governance tasks for Microsoft 365 and Copilot35–40%

Explore key topics

The largest domain. Microsoft Purview surfaces — Information Protection, Data Loss Prevention (DLP), Insider Risk Management, Communication Compliance, Data Security Posture Management (DSPM) for AI, and Data Lifecycle Management. Sensitivity labels, data classification, retention. Understand how Copilot accesses data, how Microsoft Graph influences Copilot responses, and how Copilot uses M365 / Purview / Defender controls to protect against risk. Use Compliance Manager, Data Explorer, Insider Risk, Communication Compliance, Activity Explorer, DSPM for AI, and Content search in eDiscovery. Identify and monitor SharePoint oversharing — including SharePoint Advanced Management's restricted site access. Around 14–18 questions.

Perform basic administrative tasks for Copilot and agents25–30%

Explore key topics

The Copilot ops layer. Compare built-in Copilot and agent capabilities, monthly licence vs pay-as-you-go (including SharePoint), enableable / disableable Copilot features, and use cases for Researcher, Analyst, and custom agents. Assign Copilot licences. Monitor PAYG billing policies. Track Copilot usage and adoption via Copilot Analytics in the M365 admin centre. Manage prompts (save, share, schedule, delete). For agents: configure user access, create an agent, understand the agent approval process, and monitor agents (usage, operational insights, lifecycle) via M365 admin centre and Microsoft Power Platform admin centre. Around 9–14 questions.

Frequently asked

AB-900 FAQs

How much does the AB-900 exam cost?

AB-900 is a Fundamentals-tier exam. The voucher is USD $99 in the United States; in the UK it's typically around £75. Microsoft regularly offers free vouchers via Microsoft Build, Microsoft Ignite, and free virtual training events for Fundamentals certifications, so check your Microsoft Learn profile for active offers before booking. Fundamentals certifications do not expire, so there is no annual renewal cost.

Does the AB-900 certification expire?

No. AB-900, like other Microsoft Fundamentals certifications (AZ-900, AI-901, SC-900, DP-900), does not expire. Once earned, the credential is yours permanently. This is in contrast to Associate and Specialty certifications which require annual renewal on Microsoft Learn.

What is the AB-900 retake policy if I fail?

The first retake is allowed after 24 hours. Second and third retakes each require a 14-day wait. Microsoft caps retakes at five attempts per 12-month rolling period. Each attempt requires a new voucher purchase. AB-900's Fundamentals tier means questions are broader than they are deep, so most retake failures come from skipped Purview / Defender XDR content rather than M365 admin centre topics.

How long should I study for AB-900?

Most candidates pass AB-900 after two to four weeks of focused study, assuming basic Microsoft 365 admin familiarity. If Microsoft 365 admin centres and Microsoft Entra are new to you, plan for six weeks — the exam expects you to recognise admin-centre objects (Exchange, SharePoint, Teams, M365), Purview surfaces (Information Protection, DLP, Insider Risk, DSPM for AI), and Defender XDR features. Azure Mastery's readiness gauge tells you when you're at exam-ready; don't book until it shows roughly 720 or higher.

AB-900 vs SC-900 — which should I take first?

Different scopes. SC-900 (Security, Compliance, and Identity Fundamentals) is the broad Microsoft security overview — Entra, Defender, Purview, compliance, identity. AB-900 is narrower and more practical: it focuses on Microsoft 365 Copilot administration, with security and Purview coverage scoped to the Copilot / agent threat surface (DSPM for AI, sensitivity-label flow into Copilot grounding, oversharing in SharePoint). If you already passed SC-900, AB-900 will feel like an extension. If you're starting fresh and your role is M365-Copilot-focused, take AB-900 directly first.

AB-900 vs AB-620 — what's the difference?

Different jobs. AB-900 is the Fundamentals-tier admin cert: it expects you to identify Microsoft 365 admin-centre objects, Purview governance surfaces, and Copilot administration controls (licensing, usage analytics, agent approval flow). AB-620 (AI Agent Builder) is the Associate-tier maker cert: it expects you to build agents in Copilot Studio with topics, generative answers, knowledge sources, and channel deployments. AB-900 administers; AB-620 builds. Many M365 admins take both because real-world Copilot rollouts require admin governance and maker support.
